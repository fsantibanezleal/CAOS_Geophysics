# Attribution

Inverse Earth Studio was implemented as an original CAOS research workbench. The scientific framing and framework choices are informed by the following public projects and papers:

- SimPEG: Cockett et al., 2015, https://doi.org/10.1016/j.cageo.2015.09.015
- SimPEG electromagnetics: Heagy et al., 2017, https://doi.org/10.1016/j.cageo.2017.06.018
- Choclo: https://www.fatiando.org/choclo/
- MTpy: https://github.com/MTgeophysics/mtpy
- Deepwave: https://github.com/ar4/deepwave
- Devito FWI tutorial: https://www.devitoproject.org/examples/seismic/tutorials/03_fwi.html
- OpenFWI: https://github.com/lanl/OpenFWI

No external repository code, notebook, figure, or dataset is bundled as a public replay artifact. External source availability and licensing should be reviewed again before adding redistributed observations.
