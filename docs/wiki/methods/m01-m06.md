# Methods wiki: geophysics M01-M06

This chapter records the implemented science, assumptions, reproducibility and open acceptance limits for the first six method IDs in the [product SDD](../../design/SDD.md#4-method-ladder-and-acceptance-oracle). They are distinct workflows: gravity reduction is not inversion; interpolation is not magnetic leveling; a magnetic forward operator is not a susceptibility inversion; and MT tensor quality control is not a subsurface model.

## Evidence vocabulary

**Implemented component** means code for the named operation exists. **Partial** means at least one component exists but its complete method vertical, data/case coverage, host or release gate remains open. **Planned** means the named code or gate is absent. A test pass establishes only its tested behavior in its tested scope. Synthetic known truth validates numerical behavior under construction assumptions; it is not field geology. Local and deployed/host acceptance are separate.

Commands below do not download data. Preserve original bytes and hashes, source rights, units, sign, coordinate references and correction lineage. A field example that fails admission remains a negative result, not an inverse.

## M01. Gravity station reduction and equivalent-source transforms

### Scientific question and formulation

M01 starts from gravity station records with explicit measurement, sign, units, position, height reference and correction state. It computes a traceable anomaly and, separately, estimates spatially supported values using an equivalent-source layer. Neither output is a unique density model.

Let \(g_o\) be the original downward absolute gravity converted to mGal, \(\phi\) latitude in degrees, \(h_r\) receiver ellipsoidal height in metres, and \(h_s\) ground-surface ellipsoidal height in metres. \(\gamma(\phi,h)\) is WGS84 normal gravity in mGal. The implemented sequence is

\[
g_1=g_o-\gamma(\phi,0),\quad
g_2=g_1+\gamma(\phi,0)-\gamma(\phi,h_r),
\]
\[
g_3=g_2-2\pi G\rho h_s,\quad g_4=g_3+t_s.
\]

Here \(G\) is gravitational constant, \(\rho\) the declared Bouguer density in kg m\(^{-3}\), and \(t_s\) a caller-supplied signed residual to the infinite-plate terrain term in mGal. Boule computes normal gravity and Harmonica computes the infinite Bouguer plate. The implementation does not calculate terrain from a DEM: an explicit terrain residual, matching density, datum, station order and source hash is required.

For the transform, let \(d_i\) be processed anomalies (mGal), \(\sigma_i\) declared uncertainty (mGal), \(A_{ij}\) the pinned Harmonica equivalent-source kernel at declared source depth, and \(c_j\) source coefficients. On fit set \(T\), solve the weighted damped problem

\[
\min_c\sum_{i\in T}\frac{(\sum_j A_{ij}c_j-d_i)^2}{\sigma_i^2}+\lambda\|c\|_2^2.
\]

Depth/damping selection uses inner spatial folds; a blocked outer set remains sealed until final scoring. The grid is masked outside the fit convex hull and configured distance support. The code reports unsupported cells as null, not measurements.

### Eligibility, algorithm and status

`data-pipeline/gravity_processing.py` validates the closed dataset/config, pinned engine versions, sign/unit/datum, state and digest-linked prior corrections. It converts orthometric heights only with supplied geoid separation, applies only the next declared correction(s), records correction vectors and input/output hashes, then propagates the declared first-order uncertainty policy. It rejects double/backwards corrections, unreconstructable history, duplicate stations, inconsistent sign, invalid height geometry, missing terrain semantics and undocumented error dependence.

`data-pipeline/gravity_transforms.py` admits only explicitly processed anomaly semantics and lineage. It freezes spatial train/inner/outer partitions, fits weighted equivalent sources, checks conditioning and coverage, scores only supported holdout values, and exports replayable arrays/provenance. It rejects absolute gravity or ambiguous FAA/CBA labels, unknown background/corrections, duplicate coordinates, excessive oversampling, unsupported extrapolation and infeasible folds.

**Status: implemented components, partial method.** Tests cover correction lineage, normal gravity and plate sign oracles, no-double-correction, datum/uncertainty propagation, terrain semantics, shared errors, blocked leakage, nonuniqueness and support masking. Authored/analytic examples are not field validation. The SDD's Bartlett Springs candidate had attachments unavailable (403) at review, so provider bytes/hashes were not verified.

## M02. 3D gravity prism forward response and bounded inversion

### Formulation

For receiver \(i\), active prism cell \(j\), density contrast \(m_j=\Delta\rho_j\) in kg m\(^{-3}\), and fixed background \(b_i\) in upward mGal, the pinned integral prism engine predicts

\[
d_i^{pred}=b_i+\sum_j G_{ij}m_j,
\]

where receiver and mesh coordinates are local ENU metres, \(G_{ij}\) has units mGal per kg m\(^{-3}\), and receivers must be outside the full mesh volume. With residual \(r=Gm+b-d\), supplied standard deviations or full covariance \(C\) in mGal\(^2\), and whitening operator \(W\), the L2 fit is

\[
\Phi(m)=\|Wr\|_2^2+\beta\Phi_m(m;m_{ref}),\qquad l_j\le m_j\le u_j.
\]

The implemented regularizer is volume-normalized smallness plus first-order smoothness with explicit physical length scales and reference model; second-order terms are zero. Beta is dimensionless under the declared normalization and selected on development folds. A separate sparse/IRLS implementation uses actual SimPEG sparse regularization stages. Its iteration/history values are regularizer reweight updates, not observations or necessarily optimizer steps.

### Algorithm, controls and status

`data-pipeline/gravity_forward.py::forward_gravity` calls SimPEG 0.25.2/Geoana 0.8.1 with float64 RAM sensitivity and verifies geometry, order and native `dpred = Gm`. `data-pipeline/gravity_survey_l2.py::plan_gravity_l2` freezes geometry-only blocked groups, inner validation, embargo and outer rows before observation values enter calibration. `data-pipeline/gravity_l2.py` rebuilds and verifies the actual SimPEG mesh/Jacobian, factors full covariance without diagonal substitution or jitter, calibrates candidates, fits bounded models and records terminal/KKT evidence. Its projected method is an explicitly recorded hybrid based on SimPEG ProjectedGNCG, not unmodified native convergence. `data-pipeline/gravity_irls.py` implements a distinct sparse stage policy.

Admission is closed-schema, explicit units/frame/source/process/background/noise/prior/bounds, strict array type and size limits, unique geometry, feasible blocked partitions and positive-definite covariance where supplied. Negative tests cover wrong geometry/order, invalid covariance, leakage, degenerate active bounds, null controls, line-search/native failure, false convergence and output tampering.

**Status: implemented local scientific components; full method/product partial.** The Oct. 25 local receipt records 24/24 locked synthetic controls and 213 supporting tests; the [independent receipt review](../../design/features/m02-survey-l2/reviews/independent-review-20261025.md) confirmed the scoped hashes and outcomes. It is not independent numerical reimplementation, field-data validation, user upload/API acceptance, GPU/VPS admission, UI acceptance or whole-product release approval. Bartlett Springs bytes remain unverified per the SDD.

## M03. Airborne magnetic line QC and supported gridding

### Scope and equations

M03 examines flight/tie-line geometry, height metadata and line crossover consistency, then tests whether a grid interpolator predicts entire withheld flight lines. For two intersecting segments A and B, with segment fractions \(\alpha,\beta\in[0,1]\), values \(T_{A0},T_{A1},T_{B0},T_{B1}\) in the declared field unit, the crossover difference is

\[
T_A(q)=(1-\alpha)T_{A0}+\alpha T_{A1},\quad
T_B(q)=(1-\beta)T_{B0}+\beta T_{B1},\quad
\delta_{AB}=T_A(q)-T_B(q).
\]

This is a QC residual; it is not applied as a correction. Complete flight lines are partitioned into development and an interior holdout block. A Delaunay piecewise-linear interpolator \(I_T(E,N)\) is fitted from development-line observations. For held-out point \(i\), residual is \(e_i=I_T(E_i,N_i)-T_i\), only where prediction is finite. Coverage is supported held-out count divided by all held-out rows; RMSE is the root mean square of supported residuals, in the source field unit. Unsupported areas remain masked.

### Algorithm, negative controls and status

`data-pipeline/magnetic_processing.py` requires explicit CSV columns, source digest/rights, quantity/unit, projected metric CRS, sensor-height reference, line identity/role and acquisition order. It retains outlier observations while flagging them; finds line-segment crossings from acquisition order; rejects ambiguous parallel/collinear crossings, duplicate fit coordinates, geographic degrees and excessive pair/grid budgets; holds out complete interior lines; fits only supported linear interpolation and reports holdout error and coverage. Tie lines remain QC only.

**Status: implemented processing component, partial/unaccepted M03.** Current code does **not** implement a complete source-validated flight processing chain: no verified provider-specific diurnal/IGRF correction, tie-line leveling, microleveling, continuation or comparison to a provider grid is established here. Tests use analytic planes and authored line/crossover controls, including injected tie offset; they are not measured flight-line results. The SDD Charleston line file was not acquired/hash-verified in the recorded design review.

## M04. Induced magnetic prism forward operator; survey inverse planned

### Physics and units

The ordinary forward request declares a uniform inducing field of magnitude \(F\) nT, inclination \(I\) positive down, declination \(D\) clockwise from north and ENU axes. Its direction and background are

\[
f=(\cos I\sin D,\cos I\cos D,-\sin I),\qquad B_0=Ff.
\]

For isotropic induced SI susceptibility \(\chi_j\) (dimensionless) in prism cell j, assumed magnetization is \(M_j=\chi_jB_0/\mu_0\) A m\(^{-1}\). The physical prism engine predicts secondary field \(b_i\) in nT. Returned products distinguish vector ENU, linear total-field projection \(\delta T^{lin}=f\cdot b\), and exact total-field anomaly

\[
\delta T^{exact}=\|B_0+b\|_2-F.
\]

The Jacobian is in nT per SI susceptibility. Linear TMI is an approximation for weak secondary fields; the exact norm is nonlinear. They are not interchangeable.

### Implementation, assumptions and status

`data-pipeline/magnetic_forward.py::forward_magnetic` validates mesh, active-cell order, receiver exterior, units and inducing-field metadata, calls the pinned SimPEG/Geoana integral engine, checks its `dpred`/Jacobian identity, and derives vector/scalar outputs. It assumes uniform induced magnetization, no remanence, no self-demagnetization, scalar isotropic susceptibility and a uniform background. It does not verify that a field vector is IGRF or prove the earth is induced-only. Tests compare the actual engine with independent Choclo prisms, volume quadrature and far-field controls and include null, scaling, field-direction, remanent and wrong-field negatives.

`data-pipeline/magnetic_survey_json.py` and `magnetic_survey.py` are strict input/geometry planning foundations. The full inverse is **planned**: `data-pipeline/magnetic_inverse.py`, optimizer adapter, user-survey runner, bundle and full gates named in [M04 requirements](../../design/features/m04-survey-inversion/requirements.md) are absent in this checkout. The design explicitly says the current prism operator is not a user-survey inverse.

**Status: forward component implemented and boundedly validated; complete M04 method partial/planned and unaccepted.** Prism fixtures are constructed controls, never field geology. The potential-field recovery artifacts elsewhere are not interchangeable with this typed user-survey method.

## M05. MT/EDI tensor, variance, frame and dimensionality QC

### Quantities and screen

For frequency \(f_k\) in Hz, the complex impedance tensor \(Z_k\) relates horizontal electric field \(E\) to magnetic field strength \(H\). Raw EDI variance blocks \(v_{ij,k}\) are preserved; they are not automatically a calibrated covariance. In a declared conservative screen, \(\sigma_{ij,k}=\sqrt{v_{ij,k}}\) is used as a generous per-real/imaginary scale. The parser's `mt` convention is mV km\(^{-1}\) nT\(^{-1}\); its conversion to ohms is \(Z_{ohm}=\mu_0\,1000\,Z_{mt}\), because \(H=B/\mu_0\). This factor is applied by `data-pipeline/edi.py`; the numerical values are not identical across conventions. The alternative `ohm` convention is already SI impedance.

An ideal 1D isotropic tensor is antisymmetric with zero diagonals. Set \(a_k=(Z_{xy,k}-Z_{yx,k})/2\), \(J=[[0,1],[-1,0]]\), and

\[
Z_k^{1D}=a_kJ,\qquad q_k=\frac{\|Z_k-Z_k^{1D}\|_F}{\|Z_k\|_F}.
\]

The separate necessary component gate computes all-period normalized diagonal and conservative off-diagonal-sum WRMS. Its threshold is a repository screen, not a universal standard. Phase-tensor diagnostic \(\Phi=\Re(Z)^{-1}\Im(Z)\) reports scalar departure, skew and conditioning where usable. It is context only; passing a phase tensor does not override full-complex tensor failure.

### Algorithm and status

`data-pipeline/mt_field_qc.py` reads original EDI blocks, validates complete frequency/impedance/variance counts and finite nonsentinel values, compares every frequency, complex tensor and variance with `mt_metadata`, retains rotation and tipper masks, then calculates full tensor and phase tensor diagnostics. `data-pipeline/edi.py` is the stricter parser/convention-normalization path used by the inverse. Unsupported layouts, missing/nonpositive errors, parser disagreements, arbitrary covariance-free rerotation and ambiguous signs/units fail closed.

**Status: QC and parser components implemented; method remains partial.** M05 is not an inverse or automatic 1D eligibility. The Clear Lake `cl061` source is QC-only because its current full-complex 1D gate fails. The independent C15 screen also rejects its 1D inversion despite its provider phase-tensor class. Local API integration exists but actual ML-VPS admission is a separate pending gate. `app/mt_compute.py`, `app/worker.py`, `frontend/src/api/mt-processing.ts` and `frontend/src/components/MtProjectWorkbench.tsx` are integration paths, not proof of live host activation.

## M06. Bounded 1D layered-earth MT impedance inversion

### Forward physics and objective

Under a declared quasi-static, isotropic, 1D plane-wave model and \(\exp(+i\omega t)\) convention, layer resistivity \(\rho_j\) is in ohm m, finite thickness \(h_j\) in m, frequency \(f\) in Hz, \(\omega=2\pi f\) s\(^{-1}\), and \(\mu_0\) in H m\(^{-1}\). Starting from bottom halfspace,

\[
Z_N=\sqrt{i\omega\mu_0\rho_N},\quad k_j=\sqrt{i\omega\mu_0/\rho_j},\quad w_j=\sqrt{i\omega\mu_0\rho_j},
\]
\[
Z_j=w_j\frac{Z_{j+1}+w_j\tanh(k_jh_j)}{w_j+Z_{j+1}\tanh(k_jh_j)}.
\]

Surface impedance is ohms; apparent resistivity is \(\rho_a=|Z|^2/(\mu_0\omega)\) in ohm m and phase \(\arg Z\) in degrees. With \(x_j=\ln\rho_j\), selected frequencies \(A\), impedance errors \(\sigma_k\) in ohms per real/imaginary part, and fixed thicknesses, the code minimizes

\[
\Phi=\frac{1}{2|A|}\sum_{k\in A}\left[\left(\frac{\Re(Z_k-Z_k^{obs})}{\sigma_k}\right)^2+\left(\frac{\Im(Z_k-Z_k^{obs})}{\sigma_k}\right)^2\right]
+\frac{\beta}{\max(n_L-1,1)}\sum_{j=1}^{n_L-1}(x_{j+1}-x_j)^2.
\]

Beta is dimensionless for this normalized objective; resistivity bounds, component and layer thickness are explicit. Thickness is not estimated.

### Implementations and eligibility

Two implementations must be kept distinct. `data-pipeline/electromagnetics.py` provides seeded synthetic replay solvers and synthetic comparators (TRF, Adam and per-sounding neural). `data-pipeline/edi.py::invert_edi` is the strict original-EDI path: raw block validation, explicit unit/sign/variance interpretation, parser comparison, M05 full tensor screen, selected eligible off-diagonal component, bounded CPU TRF, frozen frequency holdout, multi-start and thickness/beta sensitivity. `app/mt_compute.py` and `app/worker.py` provide an authenticated upload/job integration with ownership/resource controls; the host gate remains separate.

Missing/ambiguous units, sign, error convention, rotations, incomplete tensors, invalid variance, duplicate frequencies and any failed M05 gate reject inversion. The fit uses fixed thickness; local identifiability and bootstrap results are conditional on this parameterization/error model, not posterior uncertainty or calibrated field coverage. Tests include independent impedance oracles, parameter effects, heldout frequencies, failed/ineligible cases, malformed or tampered source bytes, ownership and worker refusal.

**Status: synthetic forward/recovery implemented; uploaded-EDI inverse implemented conditionally; field result and host release unaccepted.** Clear Lake `cl061` and screened C15 are not eligible inversions. Synthetic target models are test truth only, and the inverse does not consume that truth. No field geological solution is established.

Impedance and apparent resistivity/phase are related views, not independent data. A close curve fit does not prove unique layering. Report predictions, held-out residuals, bounds, sensitivity and unresolved layers together.

## Cross-method distinctions

| Method | Input | Primary output | Does not establish |
|---|---|---|---|
| M01 | Gravity stations and correction history | Reduced anomaly and supported spatial transform | Unique density or valid unknown upstream corrections |
| M02 | Processed gravity, mesh, noise and fixed background | Bounded density contrast, prediction, residual and coverage | Unique geology from synthetic truth |
| M03 | Flight/tie lines with order and projected coordinates | Crossover QC, supported grid, blocked-line metrics | Applied leveling or provider-equivalent correction |
| M04 | Susceptibility cells and declared inducing field | Induced prism vector/scalar forward response | Completed measured-survey inverse |
| M05 | Original EDI tensor and conventions | Parser/frame/variance/tipper QC and necessary 1D screen | Proof of 1D geology or an inverse |
| M06 | M05-eligible impedance and explicit errors | Conditional fixed-thickness model and held-out fit | General 2D/3D structure or field truth |

For whole-product status use the SDD's complete [M01-M13 acceptance matrix](../../design/SDD.md#4-method-ladder-and-acceptance-oracle). This chapter is only the technical wiki for M01-M06; it does not represent overall release acceptance.
