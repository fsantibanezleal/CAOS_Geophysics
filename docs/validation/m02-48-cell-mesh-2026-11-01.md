# M02 48-cell starter mesh validation

## Scope

The authenticated uploaded-gravity workbench now proposes a uniform 4 × 4 × 3
mesh (48 active density unknowns) instead of its former four-cell 2 × 2 × 1
mesh. The frontend exposes easting, northing, and elevation counts, each
bounded to 1–64, with a 4,096 total-cell limit matching the method contract.
The default covers the station x/y coordinate bounds (with a 25 m minimum
horizontal span for narrow surveys) and places the mesh top one layer below
the lowest station elevation. This is an inversion parameterization, not
a geological target or a resolution claim.

Applying a new resolution preserves the horizontal extents and top elevation;
vertical depth follows the requested layer count. It uses the intersection of
the previous prior bounds, activates every new cell,
and resets per-cell start and reference values to the nearest feasible zero.
The control copy states these effects before application. The exact JSON editor
remains available for custom geometry and active masks.

## Remaining limits

The calibration is an authored synthetic control, not an uploaded survey. No
field recovery, GPU acceleration, hosted execution, or M02 deployment is
claimed. A real uploaded M02 browser result and host resource acceptance remain
open.
