# M13 local browser QA — 2026-11-13

## Result

The existing built frontend bundle passed the focused real-trace browser QA in
Chromium using the reviewed public asset overlay at
`frontend/public/data/phase/stead`. The page ran the trained ONNX model in the
browser, rendered the measured E/N/Z waveform and N/P/S score curves, showed the
locked held-out benchmark, and refused inference for the retained QC-rejected
row. The local-file path also accepted a JSON trace derived from a real STEAD
record and rejected the same record when its declared sample rate was changed
to 50 Hz.
