# Scientific content, UI and refinement validation

Release: 0.03.000. Local validation date: 2026-09-24. Issue: #11.

## Numerical execution

All 120 canonical case/condition files were recomputed; both neural checkpoints were retrained.
The potential mesh has 10,752 cells (80 × 80 × 70 m). Seismic has 128 × 96 nodes
at 12.5 m, a 0.5 ms internal increment and unchanged 1.1 s duration.
CNN targets contain 24 × 28 column densities.

- Local numerical suite: 15 passed, including Deepwave float64 directional derivatives on CUDA.
- Device record: NVIDIA GeForce RTX 4070 Laptop GPU; PyTorch 2.14.0+cu126.
- Frontend suite: 15 passed, including all MT truth-response parity checks, six bilingual chapters,
  eleven algorithms, KaTeX parsing, rejected-copy removal, shared CSS ownership, SVG language/theme
  contracts, metric/history definitions and isosurface orientation.
- Artifact validation: 20 distinct reference truths, 120 conditions, 324 method results; hashes,
  byte sizes and checkpoint integrity passed.
- TypeScript and production build passed. Ruff and repository guards passed.
- Canonical data: 447,727,868 bytes; largest individual artifact: 11,239,818 bytes.

The three-grid forward diagnostic is in [refinement.json](refinement.json), generated by
`scripts/check_refinement.py`. Uniform-prism subdivision agrees to 1.73×10⁻⁹ relative
difference. Ten of twelve shapes have lower response error against the finer reference; the basin
and opposing-body shapes do not. Discontinuous cell-centre boundary sampling is not monotonically
convergent. No universal accuracy or seismic convergence claim is made.

## Browser checks

Checked with the Codex in-app browser against the local development build.

- All twenty reference cases loaded actual arrays and rendered without a load alert.
- Data, Inversion and Case analysis were opened for representative gravity, magnetic, MT,
  seismic, joint and learned cases. The analysis includes current result values and metric definitions.
- All eleven Implementation algorithm panels rendered equations with zero KaTeX errors.
- All six Methodology chapters were checked in Spanish; six experiment protocol tabs in English.
- All seventeen family/method combinations in Benchmark populated numerical tables without
  NaN, Infinity or unavailable values.
- Five architecture diagrams switched to Spanish labels; light and dark palettes inherited shell tokens.
- Live MT resistivity changes updated the plotted forward response. Acoustic playback advanced time.
  Angle step, rotation, northing cut, cell/isosurface selection, section index, reduced coverage and
  mobile control disclosure were exercised.
- Responsive checks include 1280 × 720, 1600 × 900, 2560 × 1440 and 390 × 844. Mobile uses contained panel
  scrolling and the shared horizontally scrollable navigation; there is no whole-page horizontal overflow.
- Computed body font is the shared ui-sans-serif/system-ui stack. Dark body colour is rgb(13,17,23),
  matching the shell token. Product CSS declares no palette, font-stack or shell-page overrides.

Browser styling checks establish conformance and working controls, not user design acceptance.
The renderer interpolates cell data for an isosurface; it does not claim extra numerical information.

Local validation and remote promotion are complete. Both hosts passed exact artifact and route-HTML

## Remaining scientific boundaries

These remain synthetic studies. No field-data validation, posterior uncertainty, PGI or EDI inversion
is added by this release. The shared-grid cross-gradient coefficient is mesh dependent. The CNN
baseline is not noise matched, and the autoencoder still misses both withheld reference geometries.
Those separate extensions remain under issue #10.
