# PyTorch

PyTorch is the accelerator and differentiable-learning lane. The GPU setup targets the local RTX 4070 using an official CUDA wheel. The learned methods use seeded parameters, held-out case groups, explicit normalization, and a residual or novelty guard. A model score without the data split and response residual is not treated as evidence.

Reference: [InversionNet](https://doi.org/10.1109/TCI.2019.2956866), [OpenFWI](https://github.com/lanl/OpenFWI), and the physics-informed review at [Louboutin et al.](https://doi.org/10.1190/geo2023-0615.1).
