# Choclo

Choclo supplies optimized gravity and magnetic forward kernels implemented with compiled numerical loops. It is useful for larger potential-field grids and for comparing a vectorized analytic result with an established kernel implementation. The release keeps the analytic certificate independent so a missing optional engine never creates a silent substitution.

Reference: [Choclo overview](https://www.fatiando.org/choclo/dev/overview.html). Choclo is BSD-3-Clause; its use in a local environment is recorded separately from the original synthetic content.
