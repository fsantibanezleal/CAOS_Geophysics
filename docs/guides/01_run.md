# Local reproduction

Run each environment setup command separately: `scripts/setup.ps1 -Gpu`, `scripts/setup.ps1 -Api`, `scripts/setup.ps1 -Ert`, and `scripts/setup.ps1 -M08` (Windows); use `scripts/setup.sh --gpu`, `--api`, `--ert`, and `--m08` (Linux). Python 3.12 and NVIDIA-compatible CUDA wheels are required for GPU validation. The runner uses separate ignored environments for offline science, pyGIMLi profiles, API/service checks, and waveform checks. No editable package installation is used.

The M07 ERT, M09 travel-time, and native parameter-mesh tests run in `.venv-ert`; they must not run in `.venv-pipeline`, which does not include the pinned pyGIMLi solver.

For the six-route responsive/theme/language UI gate, first build `frontend`, then run `npm run gate -- --out <absolute external evidence directory>`. The output path is required and must be outside every Git checkout. Optional `--routes`, `--sizes`, `--themes`, `--langs`, `--idle-ms`, and `--settle-ms` flags select a scoped capture matrix.

The committed `data/derived/v2` tree is the validated release. On Windows, first run `python data-pipeline/acquire.py --source-id clear-lake-cl061` to retrieve and verify the exact EarthScope EDI object under ignored `data/downloads/clear-lake/`. An exact local copy may instead be supplied with `--file <path>`; see the [source guide](05_sources.md). Then run `./scripts/rebuild-release.ps1`. The script fails before a GPU bake if the station source is missing or the output is not under ignored `data/experiments/`. It computes all 120 conditions, trains both learned models, assembles synthetic EDI fixtures and the measured no-inverse tensor screen, builds the catalogue, and runs both release validators. Full acoustic FWI is GPU intensive and can take a long time. Use `-ReuseTrained` only to hash-check and reuse the published frozen checkpoints; case inference still reruns. The original synthetic EDI fixtures are under `data/fixtures/edi/`. To assemble and validate a numerical candidate already baked separately, use `./scripts/rebuild-release.ps1 -Output data/experiments/reproduction -SkipNumerical`. For a single case, use `python data-pipeline/rebuild.py --cases FWI_FAULT --variants reference --output data/experiments/fault-study`. Filtered output stays outside the canonical catalogue.

For the complete local gate, set `GEOPHYSICS_LOCAL_DATA_ROOT` to an existing external device-data directory and set the exact retained-source receipt paths (`M01_RETAINED_CORRECTION_PACKET`, `M01_RETAINED_TRANSFORM_PACKET`, `GEOPHYSICS_PROFILE_INCOMPLETE_RECEIPT`) plus `GEOPHYSICS_M11_TEST_DATABASE` to the pinned external M11 database. Then run `scripts/local.ps1 check` on Windows or `scripts/local.sh check` on Linux. Both wrappers fail immediately on a failed gate, use the pinned Python environment throughout, run the scientific runner, verify committed arrays/M13 assets/SDD structure/template boundaries, and finish with frontend tests/build. Scratch and result receipts are written under the configured external data root. The M11 database must match the exact SHA in `tests/run_validation.py`. For an ignored candidate, set `INVERSE_EARTH_DATA` and `FWI_RECOVERY_ARTIFACTS` to that candidate before running the complete numerical suite; the release script itself runs the candidate artifact and recovery validators. Also run `python scripts/validate_fwi_exports.py --data data/experiments/reproduction --report data/experiments/reproduction/fwi-replay.json` on the local CUDA machine: CPU-only CI cannot replay all 48 final wavefields. In `frontend`, run `npm ci`, `npm test`, and `npm run build` for the committed release. To inspect a candidate without changing canonical data, run `node copy-data.mjs --source ../data/experiments/reproduction`, then `npx vite --host 127.0.0.1 --port 5179`; use `node scripts/qa-recovery.mjs`, `node scripts/qa-viewport.mjs`, `node scripts/qa-interactions.mjs`, and `node scripts/qa-field-screen.mjs`. The public build copies committed results without training. The numerical test runner saves JUnit and GPU environment evidence.
