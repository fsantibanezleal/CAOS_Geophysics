# Fixed private joint execution and custody

The scientific workflow uses original supplied gravity/magnetic observations,
not the course's canonical replay. Its16 independent fits and10 positive-coupling
fits, validation-only selection, durable freeze, post-freeze sealed diagnostics,
exact face-averaged Gram and all accepted native states are described in the
[joint result guide](22_local_joint_survey.md) and the
[protected design](../design/features/joint-protected-processing/design.md).
Execution does not establish field validity or repair the separate precision
comparisons. A failed fit or full precision matrix remains failed.

The fixed child is `scripts/joint_processing_child.py`; the existing singleton
worker uses the owned `app/joint_worker.py` execution seam. Only installation
configuration selects an interpreter/site/source tree. Uploaded JSON/NPY/raw
members cannot select modules, files, callbacks, optimizer policy or runtime.
The parent-only bounded control binds exact context/job/owner/project/dataset
identities, original member hashes and a single absolute monotonic deadline.
All device paths enter through configuration. Data and scratch roots are explicit
ordinary external directories, disjoint from source and each other; repository,
system-temp, relative, reparse and reused stage paths refuse. Original source
dependencies are indexed and materialized through the
[native dataset contract](../data-contract/06_joint-native-datasets.md).

The child disables site startup and bytecode, verifies the closed product source
inventory and original targeted vendor pins before importing numerical libraries,
and uses the registered Windows CPython3.12.10 single-thread runtime. It runs
actual solve, strict original replay, native-state export and another strict
instrument replay. Source/context bytes are rechecked between phases. No phase
extends the parent's lower wall deadline. Original native optimizer predicates,
physical objective/gradient/Hessians and internal limits remain unchanged.

The observer charges the complete child-tree sampled RSS and the SUM of stage
and scratch bytes. Lower configured limits bind, with600seconds,2GiB RSS and
original256MiB scratch maxima; stdout/stderr independently bound64KiB. Cancel,
wall/RSS/scratch/log failure stops owned work and retains known inputs, actual
accepted-state artifacts and logs. Measurement failure is failure, not zero RSS.
If process enumeration itself fails, the owned process handle is terminated and
descendant termination is explicitly unverified. This is not an OS reservation
or kernel-enforced host receipt. Unknown or uncertain bytes are never swept.

`receipt.json` binds actual phase receipts, source identities and the exact SHA
of `loaded-modules.json`, containing actual imported package source/binary hashes.
These retain provenance without claiming full transitive/native closure. The
supervisor's independent receipt binds control/child SHA, deadline, limits,
actual counters, exit/failure and any termination verification. Both explicitly
leave scientific acceptance, host admission and public activation false. The
original v1 arrays, selection and historical failure receipts are not rewritten.

After child exit, invalid JSON, missing or changed receipt/context/originals
produce a literal failed supervisor receipt. A failed validation never promotes
a candidate child digest; expiration still uses the same job deadline. The
final byte charge includes the exclusive supervisor receipt itself, including
its serialized integer byte count. Receipt-induced lower scratch overflow is
rejection, not an extra metadata allowance. A rejected stage remains charged
and retained. Independent post-write tree measurement must match the closed
count; unexpected concurrent changes require recovery, not publication.
The wall snapshot includes the final pre-write measurement using the original
observer start. The same absolute job deadline is checked through closure and
after fsync/measurement. Pre-write expiry is a failed timeout; expiry during
an uninterruptible write refuses finalization and retains an unqualified
receipt for recovery. The snapshot is not a hard-real-time write-interruption
or permission to publish a receipt whose finalization raised an error.

Gates exercise an actual full26 child, original/instrument replay, original-byte
stability and loaded magnetic source provenance; closed source/interpreter/input
controls; full-size-before-hash refusal; original lower caps; real prelaunch and
running cancellation; real child deadline/RSS/scratch/log adverse conditions.
The parent canonical claimant, result/member publication, reservations/recovery,
source-bound export and shared sidebar mount require their additive integration
gates. A passing execution receipt or unavailable method is not their completion.
