# Scientific recovery correction: evidence and implementation choices

The 2026-09-24 audit found that all 48 seismic results worsened full-domain velocity recovery, reduced-coverage magnetic results had omitted-station errors above ten noise standard deviations, and several gravity results were worse than a zero model. Forward consistency was not the missing gate. The user authorized implementation of all pending gaps after reviewing those findings. This dossier precedes the correction code and preserves the source-to-decision rationale.

## Verified primary sources

- [SimPEG L2DataMisfit](https://docs.simpeg.xyz/latest/content/api/generated/simpeg.data_misfit.L2DataMisfit.html): whiten observations and the operator using declared standard deviations. Discrepancy controls the data/prior tradeoff; an unweighted fit with a post-hoc WRMS is not equivalent when the tradeoff remains fixed.
- [SimPEG joint tutorial](https://docs.simpeg.xyz/latest/content/user-guide/tutorials/13-joint_inversion/plot_inv_3_cross_gradient_pf.html): separate two data terms, spatial regularization, sensitivity weighting and structural coupling. Compare with a matched uncoupled solution, not a different initialization/objective.
- [SimPEG PGI](https://docs.simpeg.xyz/dev/content/api/generated/simpeg.regularization.PGI.html) and [Astic et al.](https://arxiv.org/abs/2002.09515): a mixture prior on multiple physical properties is distinct from a cross-gradient. Fit the mixture from independent petrophysical samples and retain a deliberately mismatched-prior control. Our implementation must state whether it uses the full mixture likelihood or SimPEG's locally quadratic membership formulation.
- [Deepwave FWI](https://www.ausargeo.com/deepwave/example_fwi): explicit low-pass frequency progression, bounded velocity and differentiable propagation; the example itself is not field validation. Use physically specified Hz cutoffs, evaluate the complete selected state and distinguish shallow data fit from model recovery and illumination.
- [SciPy least_squares](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html): bounded TRF minimizes a sum of squared residuals. Match the normalization and bounds in the Torch comparisons. Save each model with its own evaluated loss.
- [MTpy-v2 MT object](https://mtpy-v2.readthedocs.io/en/latest/notebooks/mt_object.html): EDI is a supported SEG transfer-function format. [MTpy source](https://github.com/MTgeophysics/mtpy-v2/blob/main/mtpy/core/mt_data.py) distinguishes native MT and ohm units. [EMTF-FCU](https://github.com/magnetotellurics/EMTF-FCU) cautions that rotating EDI errors without sufficient covariance does not yield an unambiguous uncertainty transformation. Preserve components, units and rotation; reject unsupported error transformations instead of inventing covariance.

## Method and validation decisions

Potential fields retain exact prism forward operators. Add physically scaled spatial priors, uncertainty weighting, discrepancy-based tradeoff selection and complete active/omitted/model/baseline diagnostics. Sparse inversion must retain a fixed documented objective per inner solve. Do not infer a body shape, support or depth from the held-out truth to improve its inversion.

FWI retains the published propagator and independent starting trend. Use a spatially regularized multiresolution parameterization and actual frequency continuation. Acquisition and waveform windows must illuminate the declared domain. A successful nominal recovery must improve the starting model; salt/cycle-skipping remains an explicitly declared challenge, not a fabricated success. Independent-discretization and gradient checks remain separate gates.

MT compares equal residual normalization and bounds. Per-sounding neural parameterization is not a pretrained inverse. EDI fixtures are original synthetic transfer functions, distributed with full provenance; external field data, if added, require confirmed reuse rights and no invented geological truth.

Ensembles must name the conditioning and sampling law. Parametric noise bootstrap is repeatability conditional on a model, not posterior geology. Report empirical coverage, interval width and bias on separate calibration realizations, including failures. Never label the six sensitivity variants as samples from a posterior.

Learned evaluation uses identical observations and projected targets for classical and neural methods. Restore real negative controls, calibrated detection statistics and explicit distribution shift; validation chooses hyperparameters, test truth is used only for evaluation. A held-out neural failure stays visible.

## Compute preflight

Probe each changed solver in ignored experiment folders before a canonical bake. Run at most one GPU-heavy job at a time on the 8 GB laptop GPU; record peak memory and elapsed time. First smoke must return progress within one minute. Stop a probe on nonfinite values, allocation failure, objective mismatch or materially worsening nominal recovery. Do not publish a failed probe. Canonical artifacts are regenerated only after the implementation and gates agree.
