# Stable derived survey data during physical interaction

## Requirements

R-482 THE protected result viewer SHALL derive the selected original acquisition
group only when the immutable view or selected group changes. THE residual
spectrum SHALL recompute only when that group or measured component changes.
Pointer row/cell selection, camera, history, language or tab changes SHALL NOT
rerun the quadratic complete-line DFT. Gate: actual rendered pointer/control
events with a test-build-only counter around the unchanged spectrum function.

R-483 THE test SHALL use a genuine byte-verified result and preserve its original
line inventory, values and spectral applicability. A null scientific control is
usable for interaction/resource regression, not nontrivial recovery evidence.
No new spectrum thinning, interpolation, input cap, numerical tolerance or
scientific acceptance claim is permitted. Gate: authenticated binding parity,
unchanged computation implementation and same-generation numeric export.

## Design and tasks

Use React useMemo for group rows keyed by immutable value/group, and spectrum
keyed by those stable rows/component. No cache framework or mutable global
production state. Instrument only the independently compiled browser gate,
record source hashes and mark that proof instrumented. Drive actual pointer,
camera/history range and group/component controls; assert unchanged count for
presentation-only interactions and one new call for each physical input change.
M11 owns shared instrument layout; this correction introduces no shared shell,
font, base CSS, camera scaling or susceptibility colour-range change. Existing
objective history is labelled as such; missing intermediate model arrays are
not supplied by interpolation or relabelling.

1. Record an actual pre-fix interaction failure.
2. Memoize group rows and spectrum using immutable input dependencies.
3. Run pointer/control and source/typing regressions on the same verified view.
