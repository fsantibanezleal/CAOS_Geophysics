# Current M03 observation dependency binding

## Requirements

R-474 THE M04 consumer SHALL use the current M03 owner capsule, without replacing
its shared module paths with a historical replay reference. The exact dependency
is the seven observation/import modules from public 72c10d2521ccf11e281c6c398d2e7d1cfb4b76a0.
Their seven exact byte hashes are unchanged from the qualified dfe738c055e3bba6a7e1924b94091a746f6476d5
closure. The newer owner API/QR modules are not imported or replaced by this consumer.
Historical results retain their actual old-source bindings; no numerical,
resource or field claim transfers to the current capsule. Gate: exact current
source hash/path closure, unchanged consumed ABI and protocol controls.

R-475 THE M04 local binding and terminal observation SHALL include all seven
modules, including the two lazy schema dependencies magnetic_lines and
magnetic_line_validation. A shadow-loaded old module, drifted file, incomplete
receipt or old source inventory SHALL refuse before fitting. Gate: seven actual
module paths/hashes, old binding rejection and foreign root/source negatives.

R-476 BEFORE any changed-source firstfit, THE separate source qualification
SHALL verify closed ctypes layout/functions, membership-before-import refusal,
fresh accounting refusal behavior and external-file validation. It SHALL NOT
invoke M03 run_worker, its QR solver/export, M04 calibrate, or any process birth.
Gate: no-fit compatibility receipt and existing protocol/source controls with
the current owner imports. The final648 allocation remains a separate gate.

## Design

Of these seven files, five are unchanged from the retained historical source.
Only magnetic_line_survey_io and magnetic_line_survey_runtime changed. M04 uses
the runtime's public apis/query/counters/require_job, REQUIRED_FLAGS and
Basic/IO/Limits/Accounting/Memory/Security layouts. These consumed functions and
layouts are unchanged except the additive GetShortPathNameW API signature.
It does not use run_worker, cancellation markers, owner QR pipeline, worker_cwd
or configured_limits. The IO change skips probing a regular leaf as a directory;
ancestor/repository/link/type refusals remain enforced. No local shim is needed.

Extend the M04 actual loaded source inventory and retained observation pins to
include both lazy schema imports. All seven must resolve to the same explicit
current dependency root and match the current upstream byte hashes. Source
qualification is an executable checker, not a new solver/runtime framework or
automatic registry admission. Rebind newly generated local candidate requests
through the existing public binding_for_sources and source_inventory; do not
rewrite old requests/receipts. Existing retained bundles remain validated under
their recorded historical source rather than upgraded in place.

Consumer integration imports only the owned checker, two M04 inventory edits,
their tests and this specification. The seven dependency files belong to M03's
owner capsule; they are not M04 replacements. A colocated qualification tree may
contain their exact current upstream bytes to test the integration, but parent
must not cherry-pick them over a later corrected M03 owner.
