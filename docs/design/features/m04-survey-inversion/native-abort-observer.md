# Native abort observer identity and prerequisite

## Requirements

R-470 BEFORE releasing an abort-test controller, THE harness SHALL assign its
creation-retained suspended process handle to an independently held, unnamed,
non-inheritable ancestor Job and verify both limits and actual membership.
Neither process enumeration, command-line matching nor a later numeric PID
acquisition is authority for a crash verdict. Gate: assignment, membership,
readback and release refusal controls, plus actual non-scientific Windows
process-tree qualification. Those primitives do not qualify scientific work.

R-471 WHEN testing controller death, THE observer SHALL kill only the retained
controller process handle and retain its ancestor Job without terminating it
through fresh active=0, total=2 accounting within the original10s drain reserve.
The inner scientific Job stays owned by the controller alone. No inherited or
duplicated science-Job lease shall change its existing kill-on-last-close
behavior. Gate: actual nested-process primitive, delayed accounting, foreign
birth, reader refusal and expired reserve controls; actual scientific crash
qualification remains a separate prerequisite-bound gate.

R-472 IF any setup or observation fails, THE harness SHALL drain only its own
held controller/ancestor Job before closing custody. Forced exceptional cleanup
SHALL NOT become a successful scientific lifetime, cancellation, extinction or
abort verdict. Missing accounting and reserve exhaustion remain failures. Gate:
setup failure after birth, cleanup failure and unknown-count negatives.

R-473 BEFORE an original-linear scientific abort test starts a process, THE
harness SHALL generate the unchanged full original case request in memory and
check every inner and final geometry-only allocation through the production
workflow allocation seam. A refused phase SHALL leave an exclusive no-fit
receipt and a non-success exit with no controller birth. Exact-total source is
not admitted by this original-linear option. This cheap gate is necessary but
not sufficient: the externally serialized changed-source final120s fit and
independent precision must also pass before actual scientific abort/matrix
qualification. Gate: current original final648-component refusal; no new fit.

## Design and primary sources

The public M03 ctypes Job types, accounting reader and API signatures remain
the implementation dependency, not a replacement native framework. Create an
observer Job with only KILL_ON_JOB_CLOSE, no UI, breakaway, memory, CPU or active
limit changes. Launch the exact controller suspended, assign and verify before
NtResumeProcess. A child automatically inherits the ancestor Job and is then
assigned to the controller's existing inner scientific Job. Both Job handles
are separately owned; only the ancestor observer is held by this harness.

Microsoft documents nested Job ordering, inherited membership and aggregate
accounting in [Nested Jobs](https://learn.microsoft.com/en-us/windows/win32/procthread/nested-jobs),
assignment constraints in [AssignProcessToJobObject](https://learn.microsoft.com/en-us/windows/win32/api/jobapi2/nf-jobapi2-assignprocesstojobobject),
and last-handle termination in [Job Objects](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects).
These source semantics are not a claim that an actual OS gate passed.

Use fresh accounting, not a Job wait signal, to prove group empty. Count the
exact two expected births (controller and worker), with no zero default on a
failed reader. A successful observation never terminates/closes the ancestor
to manufacture worker death. Exceptional cleanup may terminate the exact owned
ancestor but preserves failure and requires confirmed drain before release.
Do not restart the10s reserve at a later signal or bookkeeping sample.

The original768MiB RSS/committed,3600CPU/7200wall and120s per-fit caps and frozen
adversarial regimes are unchanged. No scientific worker, objective, original
data, public optimizer, accepted method or service activation is changed.

## Tasks and scope of gates

1. Replace late PID observer acquisition with pre-release held Job custody.
2. Add bounded fresh whole-observer accounting and exact failure cleanup.
3. Add original-linear geometry-only prerequisite before controller birth.
4. Run portable authored negatives and actual bounded Windows primitives,
   storing receipts externally and distinguishing them from actual science.
5. Schedule genuine science cancel/crash only after changed public allocation,
   final-fit precision and shared timed-lane prerequisites pass. Never repeat
   a known failed unchanged full matrix to validate this observer.
