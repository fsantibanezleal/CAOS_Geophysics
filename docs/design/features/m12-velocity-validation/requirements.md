# M12 bounded learned velocity validation: requirements

Date: 2026-09-28. Parent: [approved product SDD](../../SDD.md), M12 and R-010. This feature is a local, first-arrival, straight-ray 2D velocity experiment. It does not operate on waveforms, claim full waveform inversion, or score field geology. It is separate from the existing `learning.py` gravity-density CNN and its 800/160/160 seed-separated records.

| ID | Requirement | Named gate |
| --- | --- | --- |
| VEL-01 | THE generator SHALL assign an entire seeded realization to one partition, train and select on layered/lens/dipping families and two acquisition layouts, and reserve fault/salt families and a third layout for a locked joint test. Separate family-only, acquisition-only, and in-distribution controls SHALL expose each shift. No test sample or layout may select weights, normalization, classical regularization or detection threshold. | `tests/learning/test_velocity_inversion.py::test_family_acquisition_partition_and_hashes` |
| VEL-02 | THE forward data SHALL come from independent fine-quadrature bilinear-slowness integration, while the learned physics term and classical inverse SHALL use cell-length rays. Homogeneous travel times and row lengths SHALL agree with geometric distance/velocity within `1e-10` seconds and `1e-9` metres; a heterogeneous control SHALL expose nonzero operator mismatch. | `tests/learning/test_velocity_inversion.py::test_independent_oracle_and_ray_geometry` |
| VEL-03 | THE trained estimator SHALL consume only noisy first-arrival times and supplied ray geometry, emit a bounded 16 by 16 velocity map in m/s, record train-only selection, and save reloadable weights plus an exact SHA-256 receipt. Fixed physical input scales SHALL be serialized; no test truth, family label or acquisition label enters inference. | `tests/learning/test_velocity_inversion.py::test_family_disjoint_checkpoint_and_forward_consistency` |
| VEL-04 | THE classical comparator SHALL solve regularized ray-slowness least squares on exactly the same noisy picks and geometry. Its regularization SHALL be selected on validation only from the frozen candidate grid `1, 10, 100, 1000`; it SHALL not receive truth or a different noise draw on test. | `tests/learning/test_split_and_benchmark.py::test_disjoint_groups_and_matched_inputs` |
| VEL-05 | THE evaluation SHALL report per-cohort and per-family velocity RMSE (m/s), independent-oracle travel-time RMSE (ms), comparator metrics, and per-record failure counts. A forward residual threshold SHALL be the 95th percentile of validation learned residuals before locked tests. OOD findings SHALL include misses and shall not be called a calibrated field detector. | `tests/learning/test_velocity_inversion.py::test_receipt_metrics_recompute` |
| VEL-06 | IF the joint held-out model or forward-data score worsens against the same-input classical comparator, or any forward residual exceeds the frozen validation threshold, THEN the receipt SHALL retain and report that negative outcome. A claim of held-out M12 advantage requires both mean model and mean forward metrics to improve, with no omitted case. | `tests/learning/test_velocity_inversion.py::test_failure_verdict_is_not_suppressed` |
| VEL-07 | THE local command SHALL run dataset generation, train, checkpoint, independent evaluation, and receipt verification without changing canonical `data/derived`, frontend, API, M09, M10, M13, or public web artifacts. GPU execution requires a free training window coordinated with M13; CPU execution is an honest local receipt and leaves the GPU gate open. | `tests/learning/test_velocity_inversion.py::test_local_pipeline_scope` |

The grid, ray geometry, families, seeds, loss, stopping rule and metric definitions are fixed in [design.md](design.md) before locked-test execution. Training is local, never CI or deploy (ADR-0074). A retained failure is scientific evidence, not an implementation pass for the full product.
