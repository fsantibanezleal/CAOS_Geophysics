# Bounded authenticated EDI M05/M06: requirements

Date: 2026-09-28. Parent: [approved product SDD](../../SDD.md), M05/M06 and R-002/003/005/006/007/009/011. This feature adds one online *user-uploaded* EDI vertical to the existing private API and singleton worker. It does not authorize deployment or claim a measured field station is 1D.

Review renewed 2026-10-03: preserve the interrupted implementation and its private outputs, integrate current develop, and verify worker admission, a verified original-byte snapshot, numerical correctness and the complete API regression suite. Related scope: issues #40, #47 and #48; actual-host admission remains in #38/#80.

| ID | EARS requirement | Named failing gate |
| --- | --- | --- |
| MT-ON-01 | WHEN an owner uploads an EDI, THE API SHALL retain the exact original bytes and bind a versioned EDI dataset to the owned raw receipt, declared units, time sign, variance meaning, tensor components and frame without rewriting the source; each worker solve SHALL read only its hash-verified byte snapshot. | `tests/api/test_online_mt.py::test_source_identity_and_m05_screen` and `::test_verified_snapshot_survives_source_drift` |
| MT-ON-02 | WHEN M05 runs, THE worker SHALL call the strict `data-pipeline/edi.py` full-tensor/variance/rotation/tipper parser and independent `mt-metadata` comparison on that owner's verified original; it SHALL report both the full QC result and the necessary 1D screen. | `tests/api/test_online_mt.py::test_source_identity_and_m05_screen` and `tests/test_edi.py::test_native_units_complex_variance_and_independent_halfspace` |
| MT-ON-03 | IF an EDI is malformed, metadata disagrees with its blocks, or its full-tensor screen fails, THEN THE API/worker SHALL reject M06 without an inverse result; Clear Lake cl061 SHALL remain QC-only. | `tests/api/test_online_mt.py::test_malformed_and_clear_lake_exclusion` and `::test_declared_physics_mismatch_fails_m05` |
| MT-ON-04 | WHEN a screened eligible sounding is submitted to M06, THE worker SHALL call `invert_edi` on those same verified original bytes with a fixed-thickness, bounded complex-impedance fit, a frozen frequency holdout, a same-input halfspace baseline, multiple starts, and beta/thickness sensitivity. | `tests/api/test_online_mt.py::test_inverse_parameter_effect_and_independent_oracle` and `tests/test_mt_recovery.py::test_multilayer_known_recovery_and_withheld_frequency_metrics` |

| MT-ON-06 | IF another principal asks for a dataset, screen, job, result, export or cancellation, THEN THE API SHALL deny access and SHALL never run that principal's source. | `tests/api/test_online_mt.py::test_bundle_roundtrip_and_wrong_principal` |

The local benchmark records wall time, peak child RSS and scratch for nominal, upper and malformed inputs. It cannot substitute for the required benchmark on the actual ML VPS; no production feature flag is set by this branch.
