# Bounded project processing and CPU worker requirements

Date: 2026-09-28. Parent: `docs/design/SDD.md` R-004 through R-007, R-011 and section 2. This unit is an authenticated, private, flag-only gravity QC processing vertical. It does not implement a gravity correction chain, forward/inverse solver, general online M01-M13 method, or public release.

R-PJ-01 WHEN an owner processes a gravity CSV raw asset with explicit projected metre coordinates, mGal observations and positive per-station mGal uncertainty, THE API SHALL parse every row into a typed, immutable versioned observation dataset, retain the original values, units, geometry, rights and raw hash, and store a hashed private derivative. Gate: `tests/api/test_processing_datasets.py::test_owned_gravity_dataset_is_typed_immutable_and_hashed`.

R-PJ-02 IF a raw format, field, station identity, coordinate, observation, uncertainty, row count or byte cap is invalid, THEN THE API SHALL reject dataset creation with a typed field-specific error and SHALL NOT create a derivative or database row. Gate: `tests/api/test_processing_datasets.py::test_dataset_parser_rejects_invalid_rows_and_metadata`, `tests/api/test_processing_datasets.py::test_dataset_rejects_missing_sigma_and_non_gravity`, `tests/api/test_processing_datasets.py::test_dataset_requires_storage_attestation`, and `tests/api/test_processing_datasets.py::test_dataset_limits_precede_parse`.

R-PJ-03 WHEN an authenticated owner selects a dataset, THE API SHALL return an explicit method verdict with a reason for unavailable methods. Only `gravity.station-outlier-flags/v1` may be admitted on its validated gravity dataset; a raw receipt alone is never eligible. Foreign dataset/job IDs SHALL be indistinguishable from missing IDs. Gate: `tests/api/test_method_eligibility.py::test_contract_filtered_methods_and_owner_isolation`.

R-PJ-04 WHEN an eligible processing job is submitted, THE API SHALL durably record an immutable canonical request and input hash, enforce one active job per account, a bounded global queue and private-byte quota reservation, and reject oversized or unsupported requests before worker execution. The API SHALL NOT run scientific processing in its request process. Gate: `tests/api/test_job_admission.py::test_immutable_request_and_transactional_admission` and `tests/api/test_job_admission.py::test_queue_and_resource_admission_are_bounded`.

R-PJ-05 WHEN the separately launched CPU worker claims an admitted job, THE worker SHALL execute only the fixed, versioned flag-only engine on that exact dataset in a child process with no shell or inherited secrets, preserve observations and uncertainty, publish a hashed immutable result with parameter and code provenance, and change flags when the threshold changes on an independent hand-calculated control. Gate: `tests/api/test_job_execution.py::test_real_flag_qc_and_parameter_effect` and `tests/api/test_job_execution.py::test_child_launch_has_fixed_command_and_no_secrets`.

R-PJ-06 IF a queued/running job is cancelled or its child fails, times out, exceeds RSS/scratch limits or the worker restarts after an interruption, THEN THE service SHALL expose a durable non-success state and typed error, terminate a live child/process tree on local cancellation/resource breach, and never publish a success-shaped result. Gate: `tests/api/test_job_limits.py::test_cancel_timeout_failure_and_recovery`, `tests/api/test_job_limits.py::test_scratch_limit_terminates_child`, and `tests/api/test_job_limits.py::test_rss_limit_terminates_child`. Actual-host crash/parent-death behavior is a separate open release gate.

R-PJ-07 WHEN an owner reads or exports a completed result, THE API SHALL verify stored dataset/result hashes and return an owner-only bundle whose arrays, axes, units, rights, parameters and provenance round-trip through a strict verifier; raw bytes and private storage keys SHALL not be exported. Gate: `tests/api/test_job_export.py::test_bundle_roundtrip_tamper_and_rights`.

R-PJ-08 WHEN a project with datasets or jobs is deleted, THE API SHALL refuse active jobs and unknown/changed derivative bytes, then include exact derived hashes in the durable receipt before deleting only verified owned files. Startup SHALL preserve and fail closed on orphaned or interrupted derived/job bytes. Gate: `tests/api/test_job_lifecycle.py::test_project_deletion_and_orphan_recovery`, `tests/api/test_job_lifecycle.py::test_delete_refuses_changed_derived_bytes`, `tests/api/test_job_lifecycle.py::test_delete_refuses_unknown_derived_bytes`, and `tests/api/test_job_lifecycle.py::test_startup_preserves_interrupted_worker_staging`.

R-PJ-09 THE API SHALL not expose a solver submission path, fabricated prediction/residual/model or scientifically `valid` verdict from flag-only QC. Gate: `tests/api/test_method_eligibility.py::test_no_solver_or_fake_result_claim`.

Open gates: Product R-006 and M01-M13 numerical verticals require independent scientific oracles and actual-ML-VPS nominal/upper/malformed resource benchmarks, cancellation/crash evidence and 30% host headroom before online release. Product R-005 also requires the frontend eligibility parity gate; R-011's full result-artifact export/reimport remains separate from this processing-only bundle. The local `data-pipeline/ingest.py` curated tar/EDI and five-column inversion CLI have no shared API ObservationDataset schema; parser parity and a reviewed adapter are INT-PJ-INGEST-01, not silently inferred here.
