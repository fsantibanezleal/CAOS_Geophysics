# Magnetic inversion theory in existing research pages

This integrates the existing reviewed nine-chapter magnetic course content into
Methodology and Implementation without requiring a fitted result. It does not
replace the verified-result course, execute a solve or assert numerical acceptance.

- MTN-01: Both existing pages expose all nine chapters in EN/ES through shared
  shell navigation; no new route, CSS, palette, font or citation provider.
- MTN-02: Each chapter retains its physical equation, explicit symbol/units,
  extended derivation, source-linked implementation boundary, assumptions and
  worked question. Arithmetic examples are teaching, never returned metrics.
- MTN-03: Theory needs no MagneticView, network result, file input, credentials,
  synthetic fitted object or inferred default generation.
- MTN-04: References resolve once through the root citation registry to pinned
  primary sources. The implementation page explains local algorithms, not file
  packaging as a substitute for science.
- MTN-05: Native keyboard chapter/reasoning controls, real KaTeX, readable prose
  and bounded equation scrolling work in light/dark, EN/ES, phone/desktop.

frontend/e2e/magnetic-theory.spec.ts; full frontend/type/build/content gates.
Render acceptance is not scientific, user aesthetic or deployment acceptance.
