# Source-linked course composition

Reuse the reviewed magnetic-survey-course, magnetic-course-derivations and
magnetic-course-citations definitions unchanged. Compose an independent theory
component with no MagneticView dependency, rather than constructing an empty or
fabricated result to satisfy the existing verified-result component's contract.

The chapter selector is labelled and bounded to the nine frozen definitions.
Each article has two shell Equation renderings with adjacent symbol definitions,
extended prose, shell Cite/Refs, an explicit implementation code location, a
Callout for assumptions, and a native details element for the worked answer.
Chapter replacement resets that reasoning disclosure via the chapter identity.
This is authored teaching, not an animation of a computation or a measured fit.

Mount the same component under one magnetic subtab in each existing Fields
group. Extend the existing CITATIONS array only; do not nest a provider.
Browser gates exercise native selection/disclosure/keyboard and all chapters
in both languages/themes at phone/desktop widths, checking horizontal document
containment while permitting equation-container scrolling. Output is explicitly
external, with source/build hashes and no scientific-data interception or API writes.
