An explicit backend-root/interpreter QA argument permits testing the actual implementation against this frontend's build with our own private store. The [MT recovery chapter](../../../problem-types/mt-recovery.md) defines exp(+i omega t), E/H impedance, native conversion mu0*1000, marginal sigma and necessary diagonal/antisymmetry WRMS <=3. [SciPy TRF](https://docs.scipy.org/doc/scipy-1.15.2/reference/generated/scipy.optimize.least_squares.html) is bounded least squares, not LM despite the legacy mt-lm array key. [EMTF-FCU](https://github.com/magnetotellurics/EMTF-FCU) documents error-convention and covariance limitations. [USGS Clear Lake](https://www.usgs.gov/data/magnetotelluric-data-clear-lake-region-northern-california) is an attributed source, not geological truth. These primary URLs were re-opened during design. No new inversion engine or uncertainty law is introduced.

## Selected-project flow

The reviewed primary ProjectProcessingWorkbench gains a gravity/MT instrument switch without a new route. MT shares the existing project/auth/raw upload lifecycle, same-origin cookies/CSRF, owner checks and abort semantics. Separate MT API/result/export adapters cannot dispatch through gravity schemas. The MT panel owns envelope receipt, authoritative eligibility, selected job and success-only result. Project/dataset/job switches immediately clear stale scientific arrays and abort old reads. Session loss clears all private state. Poll all account-visible project jobs until terminal; failures retain actual error code/message, resource receipts and cancellation state. Refresh after M05 success reads eligibility again, binding the actual QC job.

Sidebar control sections fit the viewport: Data (owned original/envelope), Run (bounded parameters), History (jobs/resources/export). The run form is one scrollable control section; irrelevant thickness/basement fields are absent for a halfspace. Phone navigation actions remain available inside the expanded rail; optional axis/unit controls expand separately, keeping the primary scientific instrument visible. Zero finite layers is a halfspace; one finite layer means two resistivities. No mask, error-floor, component selection or thickness optimization is offered: the backend freezes every fifth sorted frequency, fits Zxy only and evaluates -Zyx separately.

## Typed parsing and verification

MT-specific envelope/source/physical types bind UUIDs, hashes, bytes, parser, frequency count and explicit conventions. Successful result parsing validates ascending positive Hz, [N][2][2] real/imag/sigma, observed Zxy and -Zyx curves, apparent resistivity and principal atan2 phase, screen scores/verdict and parser source/frame/units. M05 requires inverse=null; M06 requires passing same-source QC, null truth/clean, exact request thickness/beta/mask, final-model/frame identity, real residuals and actual TRF diagnostics. Unknown untrusted JSON is never cast directly into a scientific view.

The browser verifies structural/numerical serialization consistency (not geology) including residual/WRMS and bootstrap summaries. Reuse the existing portable MT forward for final predictions if its positive-time E/H contract matches; otherwise reject the mismatch rather than substitute a display result. Preserve exact returned numbers; unit conversion is view-only. The dedicated MT ZIP verifier requires exactly ZIP_STORED manifest/dataset/result, bounded expansion, hashes over original bytes, MT manifest units/environment/source and immutable identity. Backend re-import remains the independent actual-harness gate.

## Scientific instrument and interactions

Seven question-oriented views use the established selected-project select controls: response, tensor/QC, signed residuals, imposed model, holdout/control comparisons, conditional intervals and solver/local diagnostics. Shell Tabs were inspected: their uncontrolled selection API would require duplicate navigation/state for the compact project instrument; no new tab style is introduced. Conditional inverse views exist only for returned M06. Existing ScientificPlots Plot and LayerColumn are reused/extended, not a new chart stack: <=512 frequencies and <=2 layers make accessible SVG small-multiples appropriate. Shared cursor and transformed x-domain link both components. Frequency/period changes invert the coordinate mapping, not array pairing. E/H ohm/milliohm conversions apply to both values and marginal SD. Principal phase remains [-180,180], not an unlabelled wrapped or log quantity. Apparent-rho/phase do not acquire fabricated confidence bars: only original complex marginal SD is stated. The SD-bar toggle is display-only; it does not alter errors or QC. Per-frequency normalized QC amplitudes have RMS equal to the pooled criterion, not separate frequency verdicts.

Signed observed-minus-predicted complex residuals use a common zero-centred symmetric linear range across XY/-YX and real/imag. Standardization divides each component by its own returned positive SD. Holdout markers and exact-value tables retain indices and train/holdout labels. Full tensor retains negative Zyx; sign correction applies only to comparison curves. QC per-frequency normalized departures and full-record WRMS expose every failed criterion. Tipper stays ancillary with raw-variance meaning and missing masks, never fitted.

LayerColumn is a literal fixed-depth 1D profile with infinite basement, not a 3D Earth. Model tables expose imposed depth, estimated rho, initial/selected start, pointwise percentile bounds and unresolved/bound flags. Conditional samples/seed/failures are inspectable. Comparator tables show returned model, training objective/WRMS, heldout WRMS, status/stop and altered beta/thickness; no output curve is invented when the contract supplies only a summary. Objective history labels residual evaluations, including rejected trials, not accepted iterations. Equations/citations explain actual normalization and conditioning bilingually.

## Real QA and boundaries

Unit fixtures are schema-accurate test-only independent analytic contracts, never bundled app samples. Actual loopback harness executes register/verify/login/project/upload/envelope/M05/M06/result/export through the real API and separate worker. Use explicit backend root and read-only isolated interpreter, bytecode disabled, loopback only, private data/staging/matplotlib cache under frontend/node_modules/.mt-qa. No production flags, canonical copies or public synthetic assets. Real pinned cl061 is read from an explicit local source argument and uploaded only to private QA; missing original is a test blocker, never a skipped fabricated replacement.

The scientific matrix visits every view in EN/ES and light/dark at 1280x800, 1600x900, 2560x1440, and 390x844, with actual pointer navigation, linked readouts, brush/pan/zoom/reset, keyboard and touch. Screenshots stay ignored and are inspected. Test actual nontrivial beta/thickness/seed effects, fixed holdout, failed/malformed QC, queued cancel, stale reads/auth, default-closed admission and exact MT bundle re-import. Host 30% disk/memory/p95/recovery gate is owner-controlled and unchanged; a local pass is neither activation nor deploy acceptance.
