Inputs below define falsifiable teaching scenarios, not reported outputs. Primary references are in the [bilingual chapters](../../../methods/gravity-processing/scientific-course/README.md); exact unchanged source pins are in the committed course-record index and its executable verifier. [Contracts](contracts.md) govern the real local workflow; this course adds no numerical engine, provider acquisition or field dataset.

## 1. Four explanatory calculators, never physical jobs

All four have an EN/ES visible label: Explanatory calculation / Calculo explicativo. They accept finite native numeric educational inputs with fixed units; empty/nonfinite/out-of-range values leave no numeric answer and show a literal bilingual validation message. No upload, file access, auto-correction of metadata, hidden assumption of measured accuracy, scientific output dataset or job receipt. On every result show the model/reference, assumptions and domain. A value change recomputes only this scalar educational equation, not a Harmonica/Verde/core solve.

| ID / chapter | Exactly editable inputs; pedagogical defaults | Formula/output and refusal boundary |
| --- | --- | --- |
| E01 / Q1 | Geodetic latitude_deg in[-90,90], default45; WGS84 surface constants fixed from research | Surface Somigliana gamma(phi,0), mGal. No height control: this calculator is not Boule's closed-form gamma(phi,h), a free-air anomaly or processed station |
| E02 / Q2 | density_kg_m3 in[1,10000], default2670; plate_thickness_m in[0,10000], default1000; G fixed6.67430e-11 SI | B=2*pi*G*rho*t*1e5 mGal and its subtractive contribution -B. Ideal infinite land plate only; no DEM, ocean, source-recovered density or receiver-height dependence |
| E03 / Q3 | a1,a2 in[-1,1], defaults1,1; sigma1_mgal,sigma2_mgal in[0,1], defaults0.02,0.02; correlation in[-1,1], default0 | Linear two-gravity-error illustration: variance=a1^2*s1^2+a2^2*s2^2+2*a1*a2*r*s1*s2; report sqrt(max(variance,0)) and sum(abs(a_i)*s_i), mGal. Coefficients dimensionless; bound is not an observed sigma. Roundoff clipping only after valid declared correlation, no repair of arbitrary covariance |
| E04 / Q6 | wavelength_m in[10,20000], default500; delta_height_m in[0,10000], default300; amplitude_mgal in[0,100], default1 | k=2*pi/wavelength, attenuation exp(-k*Delta h) and continued amplitude mGal. Ideal flat-plane Fourier mode, not the irregular equivalent-source solver. Negative Delta h refuses; no downward-continuation option |

The defaults are chosen examples, not recommended field parameters or justified error estimates. E03 zero SD can represent a defined deterministic toy; it cannot fill a missing field error. E01 uses rounded independent surface constants with an explicitly declared formula tolerance, not a promise of bit equality to the closed-form engine. E04 distinguishes incremental height from real transform absolute heights. No calculator emits an observed_absolute parent, source/processing hash, child ID or acceptance flag.

Proposed labels: Surface reference only / Solo referencia en superficie; Infinite plate only / Solo placa infinita; Linear covariance illustration / Ejemplo lineal de covarianza; Ideal source-free Fourier mode / Modo de Fourier ideal sin fuentes. Literal physics, no marketing text. Keyboard-editable number inputs and explicit Apply/Reset controls are event-driven; no animation or automatic host requests. Independent formula/unit tests and rendered controls are required after separate approval.

## 3. Exact viewer controls and what must change scientifically

- Scenario selector offers only the three verified base IDs; changing it loads another complete bound record, not another label on the same arrays.
- Height selector offers only grids actually present in that record. Show every recorded height's precision status; do not relabel a failing grid as the selected result. Picking a view never retunes depth/damping or changes selection.height_m.
- Layer-comparison selector shows recorded training_only_alternatives with their training RMSE/coefficient norm/condition and failed reasons. Do not fabricate outer-holdout metrics for every candidate or switch the selected model without a new run.
- Field/conditional-SD selector changes display only. Field uses mGal and fixed scenario-comparison limits chosen before rendering; SD uses nonnegative mGal and visibly conditional label. Limits across comparable heights are shared; no per-height auto-range that disguises attenuation.
- Coverage overlay toggles visible reasons without removing masked/unsupported rows or replacing nulls. Map axes are easting/northing in metres; grid axis order northing,easting. Residual view is prediction-minus-observation, not the MT sign.
- Theme/language controls alter only caption/palette/labels; their metric/config/identity bindings do not change. No recolour is a new physical scenario.

An editable scientific depth, damping, observed value/noise, density, height list, geometry, mask, radius, covariance or split seed is NOT a replay control. It requires a new complete local request, actual core/transform run and bound record before any new results appear. This proposal deliberately omits freeform browser physics parameter controls; future owned jobs remain MAIN-assigned and admission-closed. Explanatory scalar inputs in section1 are the sole live arithmetic lane.

## 5. Measured resource and rendered evidence required later

No new course device memory/time limit is approved here. Before proposing browser replay loading, record raw/transformed/index/plot byte sizes for all three authored records, actual parser/tree/array allocation peaks, wall/CPU, cache behaviour and mobile/light/dark measurements with source/runtime/command pins. The proposed index records measured per-artifact bytes and caps accumulated loading at bytes+1 before parsing, then checks exact length/hash; include +1, truncated, stale-length and hash-mismatch negatives. A header-only check or allocating/parsing the entire unexpected body before checking is not that gate. This does not promise a cap on the browser/network stack's own allocations. Keep one active scenario and one view, without eagerly preloading all three records or duplicating arrays for every height; measure switching/release behaviour rather than claiming memory is freed by assignment alone. Separate producer process peak, caller acquisition buffers, browser decoded objects, image decode/canvas and concurrent view copies. A32-MiB transform CLI cap is not a total-memory guarantee. Native-object adapter bounds are not raw source caps. The newer separate JSON helper's16/8-MiB raw/canonical bounds do not establish this course's browser budget or retrofit the core CLI.

For local controls measure one single-layer/single-height case and the actual approved base9-layer/3-height comparisons; for existing-bound rejection prove cap+1, depth+1, grid-node overflow and candidate overflow fail before their prohibited numerical allocations where the current test specifies it. Do not generate a maximum400-row/12000-grid/eight-height workload merely to claim a universal safe device profile. That profile needs separate scope/measurement and remains unapproved.

Future rendered QA must capture all six figures/equations and calculator validation in EN/ES, light/dark, desktop and390-pixel mobile; keyboard focus/tab behaviour, units/minus signs, null masks and source captions. Actual three-record maps use equal-aspect metric axes, consistent colour scales, covered-count labels and literal conditional uncertainty.
