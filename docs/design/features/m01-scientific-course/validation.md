# M01 course validation contract

Course integration is checked against executable source and committed scientific artifacts, not an initiative checklist. Coordination, historical approvals, runtime inventories and local audit receipts belong in the private management repository. Their relocation does not change the scientific algorithms, tolerances, generated arrays, original artifact-byte identities or failure history.

The source-integration gate reads `frontend/src/pages/Research.tsx` and requires the `M01ScientificCourse` import and its theory and implementation mounts. Component checks retain shared-shell imports and prohibit independent fonts/styles. These are source assertions, not rendered browser acceptance.

The producer boundary is `tests/test_m01_scientific_course.py --produce-course-records OUTPUT_ROOT`. It requires a fresh absent output below its explicit owned run root, the unchanged five scientific source pins and runtime versions, actual execution of all three control cases, exact export identities and independent prism comparison. Production into an existing directory is rejected. Byte-count, duplicate-key, nonfinite and immutable-original controls remain required.

Course records retain `full_method_accepted=false`; the course does not activate a field source, hosted solver or private job. Scalar explanations, recorded arrays, native local execution, browser interactions, actual-host admission and full scientific acceptance remain separate checks. Every record has original physical quantities, units, source/runtime identity and honest uncertainty restrictions.

Numerical gates are the fourteen tests in `tests/test_m01_scientific_course.py` together with unchanged correction/adapter/transform suites. Rendering gates are `frontend/e2e/m01-scientific-course.spec.ts` in EN/ES, light/dark, desktop/phone, including real pointer/keyboard interaction and corrupt-result rejection. A static-source assertion or React server rendering does not replace those real browser gates. Scientific failures are not waived by integration or coordination relocation.
