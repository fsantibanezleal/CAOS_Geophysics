## Original versus processed columns

| Provider column | Meaning and admission consequence |
| --- | --- |
| `id` | Preserve station identity; review duplicates before using `station_id`. |
| `latitude_NAD27`, `longitude_NAD27` | Original NAD27 coordinates; a documented axis-order-aware WGS84 transformation is required before the local EPSG:4326 contract. Preserve originals and transformation provenance upstream. |
| `elevation_ft_NVD29` | Original field spelling from supplied metadata. Resolve whether `NVD29` is a typo for NGVD29 and identify the actual height system. Do not silently rename or equate NGVD29 with an unspecified geoid height. Convert feet explicitly and preserve height datum/transformation provenance. |
| `observed_gravity` | Metadata states mGal, already tide/drift corrected and tied to IGSN1971 bases (980094.15 and 980119.04 mGal). It is not raw instrument gravity. It may become a calibrated-absolute input only after source bytes and required reference/geometry/uncertainty evidence are resolved. Record upstream tide/drift as applied with the provider citation; no new instrument correction occurs here. Tide removal does not by itself specify a permanent-tide reference system. |
| `free-air-anomaly`, `simple_Bouguer_anomaly` | Already reduced provider products. Preserve column identities and their reference convention; never label them `observed_absolute`. A newly chosen WGS84 disturbance is a separate derivative, not assumed equal to either provider anomaly. |
| `inner_zone_terrain_correction`, `inner_zone_code`, `total_terrain_correction` | Preserve provider code, density, extent and sign semantics. Do not directly rename a classical correction `additive_residual_to_plate` without checking its reference, density, curvature and terrain convention. |
| `Complete_Bouguer_anomaly` | Already incorporates provider Bouguer, curvature and terrain adjustments (metadata states 166.7-km terrain extent and density 2670 kg/m3). Never reapply those adjustments. Provider comparison must account for curvature and the exact normal-gravity convention, rather than treating discrepancy as a code defect. |
| `isostatic_gravity_anomaly` | Further model-dependent reduction (metadata states Airy 25-km crust and 400 kg/m3 contrast). Preserve as a distinct provider interpretation product, not an observed absolute value or a residual terrain addition. |

The metadata's reportedly suspect grain-density formula is outside this unit and is not used for density/uncertainty weights. Independent review is required before any such derivation.

## Gate and parser layout

### Attributed author archive, distinct from USGS originals

Main subsequently reported a verified author-compiled v2 archive, [Zenodo record 16975696](https://doi.org/10.5281/zenodo.16975696), CC BY 4.0: 121,295,137 compressed bytes, MD5 `7ef5beb984425bf0edabd829cf880187`, SHA-256 `337a2d9070493773af06aee11a19d591e6468ecf0f062dd75c194a04476c0cdf`. It reports 40 entries and 299,907,397 expanded bytes, including `data/ground_gravity_data.csv` (335,377 bytes), compiled aeromagnetic data and topography. Main owns safe extraction, the complete source profile and rights receipt. This branch subsequently consumed only that existing archive's small CSV member **in memory**, verifying its individual SHA-256 as `7cb3ed0c3cbac60f896a11f213ba40209c3083cb7635ab80ab7c0fd0382a1055` for a read-only negative admission test. No download, extraction or full source profile was duplicated. The author archive is not proven byte-identical to the USGS station table, and its licence/attribution must not be replaced with the USGS CC0 statement.

Its reported header is an initial unnamed index column followed by `Station_ID,lonWGS84,latWGS84,xWGS84_UTM10N,yWGS84_UTM10N,zWGS84,OG,FAA,SBA,TTC,CBA,ISO`. Preserve OG as the attributed observed-gravity product and each anomaly/correction column independently. `zWGS84` does not by its name establish an ellipsoidal receiver or surface height: independently document its physical meaning and transformation before applying normal/reference/elevation corrections. OG still inherits the principal-fact correction/reference questions. No new drift/tide fields are invented to force admission. The author's use of ISO and a SimPEG vertical sign flip is a particular modelling choice, not an instruction to relabel ISO as uncorrected gravity. The reported compiled magnetic height offset is outside this unit. The author's fallback elevation of 1200 for missing interpolated heights must be rejected/flagged, never copied.

Actual station bytes supported `test_author_principal_fact_bytes_require_physical_metadata`: exact member size/hash and header, retained OG/CBA columns, unchanged original row, and explicit rejection of a direct column-only request missing physical metadata. The [negative-admission receipt](evidence/field-admission-rejection.json) records this result; no field reference correction was performed. Upstream instrument correction facts supplied in main's FGDC evidence remain available for a future mapper, but they are not silently synthesized into the CSV-only request. The height/reference gate stays open. Availability of that alternative author source does not prove compatibility for a new physical reduction or authorize a silent change to the approved field-source case.

The exact [executable control request](../../../methods/gravity-processing/examples/station-control.json) illustrates the typed field names. It is synthetic, not a Bartlett substitute. A field adaptation must set `source_kind=field`, actual CSV SHA-256, provider rights/citation and named IGSN1971 gravity datum, while resolving the permitted tide system, coordinate transformation, WGS84 receiver/surface heights and their errors. Unknown SD or datum is an open gate, not zero. Instrument correction declarations carry `status` and `citation`; their admissible values are documented in the [other-data guide](../../../methods/gravity-processing/01_station-corrections.md).

If Bartlett cannot enter the reviewed local chain, its proper role remains an imported principal-fact QC/comparison and correction-state challenge with an explicit ineligible verdict for new corrections. This does not close the full M01 method gate and does not authorize synthetic replacement. Main owns any future provider adapter or metadata adjudication.
