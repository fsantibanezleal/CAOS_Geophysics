Required means present, not optional; NULL only where explicitly permitted. T=validated UTC RFC3339 string20..27 bytes with optional1..6 fractional digits and finalZ, calendar-valid. Source JSON rejects duplicate decoded keys, malformed UTF-8/BOM/surrogates/trailing data/nonfinite/overflow/bool integers before construction and must reach EOF.

Application canonical bytes are sorted-key compact UTF-8,ensure_ascii=False,allow_nan=False as existing ops.canonical. Hashes of preserved source fragments/files are SHA-256 EXACT bytes, not reserialization. Scientific digests remain the protected ASCII domain, never merged into application hashes. Objects below reject ALL missing/extra keys, unknown literals and future versions.
