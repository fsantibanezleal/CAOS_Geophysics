# Integrated protected waveform components

The canonical development source now includes the fixed Linux client,
installation verifier, observer/guardian interface, held publication and stage
cleanup components. The Windows path remains separate. Both retain the
scientific request, original counts/response sources and computed member hashes.

The first integrated regression stopped on a Windows deletion path failure.
Published members fitted the live destination limit, but the longer renamed
deletion destination exceeded the same interpreter's limit. All retained member
bytes remained intact. The original DELETE now checks every destination before
creating the deletion directory, moving originals or retiring database rows.
Unsupported Windows paths return an explicit refusal; POSIX has no artificial
Windows path limit.

Focused boundary and real local-user HTTP tests establish that this refusal
preserves ownership isolation, original bytes, project/raw rows and the absence
of a deletion receipt. The previously failing scientific publication/export/
deletion roundtrip passes in a supported fresh external test directory. The
original failed fixture and report remain in private validation storage.

The installation verifier also distinguishes the unprivileged caller's
root-owned custody boundary check from the privileged verifier's interior
check. It does not make root custody readable or accept an unknown boundary.

## Acceptance boundaries

Portable API tests, actual scientific member calculation and ordinary process/
pipe tests are separate from installed native containment. Authored native
resource records in those tests are never relabelled as measured deployment
evidence. Public activation still requires the merged source, actual installed
runtime, owner-scoped queue, terminal/export/restart/deletion/cancellation gates,
browser receipt interpretation and the single-ML-VPS release check.

The original numerical thresholds and native resource limits are unchanged.
No GitHub Pages deployment or secondary application origin is introduced.
