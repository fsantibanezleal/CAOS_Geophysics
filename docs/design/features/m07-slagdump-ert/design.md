# M07 Slagdump ERT design

## Authority and source boundary

The [official pyGIMLi Slagdump example](https://www.pygimli.org/_examples_auto/3_ert/plot_02_ert_field_data/) demonstrates numerical topographic geometric factors and 2D inversion of profile 11. The [fixed example-data object](https://raw.githubusercontent.com/gimli-org/example-data/3bab9c6b96a606e2ca12cbdafc8c7da4f1b73c67/ert/slagdump.ohm) is 5,435 bytes, SHA-256 `c010a11b78ea4392cb926d675e847c74010b4cdec536aacaf8db6a644e886de2`. The untruncated 58-entry upstream tree has no LICENSE/LICENCE/COPYING/COPYRIGHT file; the raw header credits BGR Hannover and Markus Furche. The source remains provider-link-only. The existing ledger and acquisition contract own byte identity; M07 adds no new fetch path or public raw mirror. Result receipts remain under ignored `data/raw/ert/` unless a separate rights review approves a specific compact aggregate.

## Interfaces and physical contract

`data-pipeline/ert.py` is a path-invoked local script, not a package or an `ingest.py` modification. It consumes the already acquired `pygimli-slagdump` raw asset via `acquire_source`, verifies source receipt, and parses the `.ohm` text independently of pyGIMLi to make physical metadata failures inspectable. The exact format is: free-text `#` provenance lines, `<N># Number of sensors`, `#x z`, N finite x/z rows in metres, `<M># Number of data`, `#a b m n R`, M rows with 1-based sensor IDs and resistance in Ohm. It accepts no guessed columns, silent deduplication, unlabelled unit conversion, nonfinite row, zero-length dipole, non-Wenner index spacing or undeclared trailer. Local survey x/z are metres, z positive upward; there is no geographic CRS or vertical datum, so absolute elevation is not georeferenced. The Wenner description and pyGIMLi x/z-axis labels support metre interpretation; the file itself does not state a CRS.

For current electrodes A/B and potential electrodes M/N, `R = (u_M-u_N)/I` in Ohm. On a flat homogeneous halfspace, `k_flat = 2*pi / (1/r_AM - 1/r_AN - 1/r_BM + 1/r_BN)` (signed distances and electrode ordering matter), and `rho_a = k R` in Ohm m. A numerical pyGIMLi homogeneous forward calculation supplies `k_topographic`. The official example specifically contrasts `k_flat/k_topographic`; the implementation must not replace the latter with the former for modelling. The flat analytic formula and a separate homogeneous halfspace forward response are independent sign/scale oracles. Mesh refinement/topography sensitivity is reported, not mistaken for a unique geological boundary.

QC records 38 sensors, 222 raw quadrupoles, monotone profile x, z range and topographic relief, index/order validity, AB spans, R sign/range and a robust flag-only outlier list. Reciprocal pairs swap `(A,B)` with `(M,N)` modulo within-pair order/sign. The pinned file has no reciprocal pair or supplied error column; `reciprocal_status=not_available`. The provider teaching example uses a 3% relative error assumption; this workflow adds an explicit 0.001 Ohm absolute floor. Both are *assumed weights*, not measured instrument errors. There is no deletion or adaptive reweighting.

## Inverse and predictive gate

The pyGIMLi 1.6.1 2.5D ERT forward/inversion engine is pinned in a new ERT-specific requirement file. Build `DataContainerERT` explicitly from validated zero-based indices and exact x/z positions. Compute numerical topographic `k` and `rho_a = R*k`; use a topography-following paraMesh via `ERTManager` with fixed `lam=10`, `paraDX=0.3`, `paraMaxCellSize=10`, `paraDepth=20`, `quality=33.6` from the official example unless an engine compatibility check requires a documented change before looking at holdout. The split is deterministic per AB-span: sort by midpoint, then source row, with every fifth row held out; spans with fewer than five stay training-only. This preserves broad survey coverage without treating adjacent quadrupoles as independent sites. The homogeneous baseline fits one resistivity from training only (log-space median of apparent resistivity), predicts withheld resistance via the same topographic `k`.

Train on the remaining quadrupoles, freeze the model and predict withheld readings by a forward call on the complete geometry. Score log-resistance RMSE against the homogeneous baseline; report train/holdout signed residuals, weighted train misfit, outcome for each holdout row or compact local arrays, Jacobian sensitivity/coverage and two predeclared perturbations: an alternate mesh parameterization (`paraDX=0.45`, `paraMaxCellSize=15`) and doubled assumed data errors. The changed meshing parameters do not guarantee fewer cells, so the actual cell count is recorded. Neither perturbation selects or retunes the primary model. Because interleaved Wenner quadrupoles share electrodes, a separate *spatial-blocked* fit withholds all quadrupoles whose A/B midpoint lies in the central 40-60% of the line extent. That fit uses the same fixed inverse settings and a new training-only homogeneous baseline. Both splits must improve their own baseline by at least 10% with normal engine stops; a failed blocked split refutes a predictive M07 claim even if the interleaved split passes. The sensitivity runs must also produce finite held-out predictions. The engine stop must occur before its 12-iteration limit, either at its conditional chi-square target or its documented <1% objective-change rule; hitting the limit alone is not convergence. If pyGIMLi cannot forward-predict holdout without refitting, or the inversion fails to converge, do not call it a field inverse. A low training residual is insufficient. No field `truth`, unique geology, reciprocal precision or Bayesian credible interval is asserted.

The result receipt includes source SHA-256, software versions, local run configuration, split indices/hash, factor diagnostics, canonical physical mesh fingerprints, model dimensions/ranges, forward values, signed residual summaries, sensitivity definition, held-out baseline/model metric, stopping state, wall time and a generated-file checksum sidecar. The mesh fingerprint sorts physical node/cell geometry and rounds coordinates to `1e-8` m, so pyGIMLi node-ID permutations and floating noise do not masquerade as a changed mesh; a materially different mesh still changes the digest. It is ignored because the source has no raw-data redistribution licence and per-row derived values may reconstruct observations. Only aggregate metadata could be considered for a later public release after rights review.

## Gate sequence

1. Source rights/identity and strict parser negative controls (ERT-01 through ERT-03).
2. Independent flat analytic/homogeneous numerical oracle and topographic factor contrast (ERT-04).
3. Fixed mesh/weights, predeclared split and actual pyGIMLi inverse/holdout forward evaluation (ERT-05 through ERT-07).
4. Documentation, ignored-result inspection and per-requirement convergence verdict (ERT-08).
