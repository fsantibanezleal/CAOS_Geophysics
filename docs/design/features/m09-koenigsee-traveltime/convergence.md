# M09 Koenigsee local gate convergence

Date: 2026-09-28. Parent [SDD M09](../../SDD.md); [requirements](requirements.md), [design](design.md), [tasks](tasks.md). This is an offline method/source gate, **not** a public product-release or field-geology acceptance. The rights decision remains `provider-link-only`; no raw `.sgt`, field model, per-pick result or plot is tracked. The authoritative detailed evidence is the ignored, checksummed `data/raw/traveltime/koenigsee-m09-inverse-<code-sha12>.json` receipt produced locally from the ledger-pinned object.

The initial unconstrained-thread run passed the held-shot thresholds, but a repeat changed some forward times beyond the strict receipt tolerance despite matching mesh hashes. This is a real reproducibility observation, not permission to loosen thresholds or overwrite its immutable ignored receipt. The method was fixed to one engine thread (not selected on heldout performance). Two separate runs of the pinned single-thread code, one from a clean environment and one from the test environment, passed the same immutable receipt comparison and the frozen whole-shot/stop gates. That supports a **conditional local predictive inverse**, not calibrated geology or publication.
