## Synthetic acceptance, without field substitution

Generate S1..S6 from the authored record generator, retain original acquisition CSV and exact truth/injected/calibration arrays; repeat twice and require exact manifest hashes. Each regime is separate and at least one reverse/heterogeneous line is retained in every usable partition. Fit parameters are fixed before opening outer values. S1 smooth analytic field compares heldout predictions at actual heterogeneous heights: proposed RMSE <=5% of heldout signal RMS, with a 1e-6 nT absolute floor for zero controls. This is a control quality target, not a field measurement uncertainty or expected field accuracy. If it fails, revise the method/plan transparently before approval, do not relax it after tuning on test data. S2 exact leveling and S3 correction checks use their independent known calibration data. S4 intentionally yields masks/ineligible operations. S5 must demonstrate inability to resolve the injected aliased wavelength. S6 must demonstrate directional geological loss alongside stripe removal.

Refinement requires common-coordinate interior comparisons at h=200/100/50 m under fixed source/candidate/split, and a separately declared source-refinement run. Within each run bounds must hold; if 3 planes exceed cell limits use distinct identified runs, not hidden tiling. Export full support/error metrics, including where the positive target fails. Production oracle agreement establishes implementation fidelity, not field geological validity. No field uncertainty/height/date/license is taken from these controls.
