# M03 algorithms, independent oracles and controls

Status: planned. Date: 2026-10-03. These are executable recipes for the paths/gates in [requirements](requirements.md), not pseudocode placeholders or implemented science. [Research](research.md) establishes primary evidence; [contracts](contracts.md) defines physical admission; [validation](validation.md) defines acceptance.

## 1. Parse, retain and enumerate

Bound byte/token/JSON complexity before array construction. Verify exact CSV/sidecar hashes, schema/rights and physical kinds. Preserve input row ordering; build secondary indexes per line/sensor ordered by supplied ordinal without mutating rows. Reject duplicate row IDs and nonincreasing ordinals. Flag repeated coordinates/times and reversed directions. Missing measurement/height/time stays null with a reason. Consecutive eligible rows form segments only within max_segment_gap_m and, when available/required, max_time_gap_s; a masked intermediate record breaks adjacency. Never connect around a gap. Compute along-track cumulative distance on actual adjacent geometry, restarting with an explicit segment-break identifier.

Enumerate candidate flight/tie segment pairs using bounding boxes and count them before intersection work. The budget counts all candidates, not just accepted crossings. If >4,096, refuse rather than silently truncate. Use float64 geometry with an explicit coordinate-scaled floating tolerance `64 * eps * max(1, coordinate_extent_m)`; this is numerical tolerance, not acquisition accuracy. Physical uncertainty and maximum height differences remain separately supplied. Record min/median/max adjacent spacing by line, perpendicular neighboring-line distance, curvature/direction reversals and endpoint coverage. Irregular flight lines require local line-spacing distributions, not one claimed global Nyquist rate.

## 2. Geometry-only sealed evaluation

Before inspecting magnetic values, persist raw/request hashes and a geometry partition manifest. Select complete flight/reflight IDs in the requested outer spatial block; do not select by residual or prefer an easy line. Exclude every training tie sample inside the outer block expanded by at least support_radius_m. Exclusion cannot generate a new segment bridging the buffer. Partition remaining complete line groups into three geographically blocked inner folds; reserve associated tie samples using the same buffer rule. Verde BlockKFold's groups argument is ignored in the retrieved API: do not delegate line protection to it. The manifest owns grouping; use explicit row indexes.

Require at least four usable geographically distinct training groups and a nonempty supported outer holdout. If the buffer removes useful coverage, report ineligible rather than shrink the buffer after seeing scores. Selection uses inner-fold RMSE in nT, reporting fold counts and coverage. Candidate order is lexicographic increasing depth then damping; ties within 1e-9 nT choose the greater damping, then greater depth, deterministically. These tie tolerances are numerical, not instrument error. Choose one candidate and fit once on all training rows. Open sealed values once, record observed-minus-predicted residuals and evaluation_count=1. New explorations never regain an untouched-test label.

Provider-processed Charleston values may already include contractor-wide leveling. Holding out those rows tests prediction of that provider product, not independently sealed calibration. Record that distinction. Independent processing evaluation needs truly untreated channels plus calibration/reference data whose dependencies obey the seal. Leveling on training crossings cannot supply offsets for held-out lines: either their calibration is independently supplied, or held-out leveled evaluation is ineligible. Retain both provider-channel prediction and processing QC lanes rather than claim one establishes the other.

## 3. Instrument/reference derivatives

Apply explicit DAG order lag -> diurnal -> heading -> main_field -> leveling -> optional microlevel diagnostic, only to operations verified not_applied. Omitted/already-applied operations remain recorded. Re-reference has its own old/new prerequisite and cannot reverse unknown provider processing. Each stage emits original-index arrays/masks and a parent/output hash.

Lag shifts navigation coordinates, not magnetic values: for measurement time t use navigation at t+tau with the declared positive-lag convention. Interpolate linearly between synchronized eligible navigation records; no end fill, wrap, extrapolation or cross-line interpolation. Freeze synthetic tau=+0.25 s solely as an authored test parameter; positive and negative shifts have independent known coordinate oracles. Diurnal subtracts synchronized base perturbation `b(t)-b_ref`, not absolute base intensity. Heading subtracts independent calibrated `a0+ac cos(h)+as sin(h)` with h clockwise from north in radians internally. Tests must distinguish east/north headings, wrong sign, degrees/radians and an already-applied state.

IGRF evaluation is not implemented by guessing a site vector. Consume an independently evaluated main-field receipt with exact generation/coefficients/evaluator/date/coordinate/datum pins. Validate NED-to-ENU `[Y, X, -Z]`, F=norm(vector), D=atan2(E,N), I=atan2(-U,hypot(E,N)) and generation/date domain. For scalar total intensity T, anomaly is `T-F_old`; re-reference of an old anomaly is `anomaly_old+F_old-F_new`. Both old and new evaluated fields are required. Finite fake height, file date or unspecified model generation fails. Independent evaluator comparison uses its published precision/rounding receipt, not a fabricated 1 nT uncertainty.

For a perturbation vector b and unit reference direction u, `u dot b` is the weak-anomaly projection, whereas exact norm difference is `norm(F*u+b)-F`. Bound their difference by `norm(b)^2/[2*(F-norm(b))]` for norm(b)<F, and explicitly test nonparallel and strong-b controls. Do not call Harmonica total_field_anomaly an exact norm-difference calculation. The scalar harmonic lane is conditional on the constant-direction approximation in contracts. RTP/default magnetization parallel to IGRF is not inferred from scalar measurements, especially with remanence; v1 rejects it.

## 4. Crossovers and offsets

For segment p0->p1 and q0->q1 solve `p0+a*(p1-p0)=q0+b*(q1-q0)` using the 2x2 determinant. Require a,b in [0,1] within numerical tolerance and nonparallel direction. Snap near endpoints only within that tolerance; deduplicate identical physical endpoint crossings with an explicit shared-endpoint relation, retaining source pair IDs. Collinear overlaps and nearparallel intersections are diagnostic refusals, not multiple artificial crossovers. Interpolate magnetic values, upward coordinate and genuine timestamps with those same a,b. Difference d is flight minus tie. Record `z_f-z_t`, time separation, interpolated coordinates/weights and admitted/denied reason.

When declared independent row sigmas exist, `var(d)=(1-a)^2*sigma_f0^2+a^2*sigma_f1^2+(1-b)^2*sigma_t0^2+b^2*sigma_t1^2`. Correlated/unspecified errors cannot use this formula as field uncertainty. Otherwise use equal weights. Common-height and time/channel criteria precede equality constraints; absence of tolerance is unresolved.

Let C have +1 for flight line and -1 for tie line, y the admitted training crossover differences, o line offsets. Solve `min ||W^(1/2)*(C o-y)||^2` with one explicit gauge per connected component: lexicographically first tie offset=0; components with no tie are ineligible. Use independent augmented QR/SVD rank check, not normal-equation inversion. Report singular values/rank, gauge IDs, offset vector and before/after residuals. Correct channel `m_corrected=m_original-o_line`. Disconnected components have separate relative zeros; they cannot become one absolute datum or obtain arbitrary relative offsets by gridding. A line absent from the calibrated graph remains uncalibrated, never zero-filled. Exact synthetic offsets verify signs/gauges; height-only gradient differences must fail before the solver can absorb them.

## 5. Equivalent-source grid and independent linear algebra

Use pinned Harmonica EquivalentSources with float64, parallel=False, explicit source coordinates, explicit positive depth/damping and one sensor/channel. Source horizontal centers derive only from training geometry, using an explicit deterministic block-geometry policy whose row-to-block map is retained. Do not take the first N rows. At most 256 sources; refuse rather than enlarge block size without a new request. Place all sources below minimum training observation upward height by the candidate depth, and require every requested prediction above all sources in a declared source-free region. Sources are a representation of a harmonic scalar potential-like function, not recovered geological bodies/magnetization.

Kernel `G_ij=1/sqrt((e_i-e_j)^2+(n_i-n_j)^2+(u_i-u_j)^2)` in 1/m. Coefficients then have nT*m units for nT data. Zero separation fails. Do not subtract an implicit data mean or add an intercept. The inspected Verde least_squares source uses unweighted column standard deviations s_j (population ddof=0, scale 1 for a constant column), StandardScaler with_mean=False, and sklearn Ridge fit_intercept=False with sample_weight. Therefore A_ij=G_ij/s_j, `min ||sqrt(W)*(A c-d)||^2 + lambda*||c||^2`, q_j=c_j/s_j. There is no undocumented division by row count. Weights are 1 for unweighted or `1/sigma_i^2` when admitted, not 1/sigma_i; global weight scaling changes damping meaning and must not be normalized silently.

Independent oracle builds G and s directly without calling Harmonica/Verde/sklearn internals, stacks `[sqrt(W)*A; sqrt(lambda)*I]` and `[sqrt(W)*d; 0]`, then solves with SciPy QR/SVD least squares. It verifies objective, coefficients and predictions at new XY/heights against the library. Require normalized prediction difference <=1e-9 plus absolute 1e-6 nT and objective agreement <=1e-8 relative on well-conditioned controls. Rank/condition diagnostics and nonfinite results are explicit; a deliberately degenerate control must fail or declare nonconverged, never pass through a magic regularizer. Solver numerical condition threshold is 1e12 for the oracle controls; a field run reports condition and refusal rather than claiming a geological confidence interval.

Two depths x four dampings x three inner folds =24 selection fits; add one final equivalent-source fit and one geometric comparator =26 fits maximum. Physical independent-oracle tests are separate test executions, not extra production candidate fits. All selection/final work is included in the child resource envelope. Fit/evaluate each sensor separately via distinct requests, not 4 sensors x26 hidden fits in one run.

The comparator is SciPy LinearNDInterpolator: Delaunay simplices, barycentric scalar interpolation, NaN outside hull converted to null/mask. Independent triangle barycentric weights and a planar scalar field provide its oracle. It does not transform height, remove IGRF or recover vector fields. Its eligibility requires declared compatible heights/datum. Refuse collinear/rank-deficient XY and height-mismatched cases. Comparisons use the same training/holdout/support domain; do not reward one method by counting more extrapolated cells.

## 6. Sampling/support and resolution

For locally nearparallel lines with perpendicular spacing d_perp and along-track gap d_along, label nominal Nyquist wavelengths 2*d_perp and 2*d_along separately. These are ideal uniform-sampling lower bounds, not guarantees for irregular surveys; curvature, gaps, height and noise can require larger scales. Grid spacing h creates output cells but cannot restore wavelengths below acquisition support. Report ratios wavelength/d_spacing and unsupported bands, not a false single resolution number.

Cell masks combine: triangulation hull, nearest eligible training distance <=support_radius_m, declared source-free plane, holes/gaps identified from geometry, and local spacing diagnostics. No interpolated values traverse masked acquisition gaps without a separately admitted extrapolation policy; v1 masks them. Predictions outside these masks may be retained as separately labelled diagnostic extrapolations, not scoreable field estimates. Heldout support coverage is a reported denominator; low coverage never improves scores by silently dropping hard points.

Refine authored controls at h=200,100,50 m with fixed training data/source/candidate/split and compare at common physical coordinates, plus a second source-depth/geometry refinement retaining observations. Count requested cells beforehand. Report relative L2 and max differences with coverage. A <5% relative L2 change on the smooth positive dipole control is a proposed numerical stability gate, not a universal field accuracy threshold. Short-wavelength alias control must remain marked unresolved even if its rendered fine grid appears smooth. No automatic resolution substitution to meet budgets.

## 7. Higher-plane prediction and FFT continuation

Equivalent-source evaluation at a higher declared plane is a physical harmonic prediction only with actual heights/datum, sources below it and a source-free domain. It is distinct from flattening irregular-height observations by a geometric interpolator. Downward continuation is unsupported; negative or zero requested continuation displacement fails (same-plane interpolation is a different operation).

FFT upward continuation applies only to an admitted complete regular scalar grid on one plane. With frequency f in cycles/m, k=2*pi*f in rad/m and positive delta_z, multiply Fourier coefficients by `exp(-sqrt(k_e^2+k_n^2)*delta_z)`. Zero-frequency stays unchanged. Persist detrend, padding, taper and crop policy; no unnoticed NaN fill. Periodic oracle uses no padding/taper; finite-domain diagnostic explicitly tests edge effects using zero or reflection padding named in request. Reflection is a boundary assumption, not measured geology. Compare with direct independent dipole values on a higher plane and report interior/boundary errors separately; the padded image cannot promise infinite-domain truth. Reject holes rather than silently invent a complete plane.

Independent single Fourier mode `A cos(k_e e+k_n n+phi)` has continued amplitude `A exp(-|k| delta_z)`. Verify relative amplitude/phase <=1e-10 on exactly periodic controls. Also compare the FFT transfer array with an explicitly computed analytic exponential, not merely two calls to the same library. Direct dipole control tests physical decay at new heights; continuation cannot be accepted solely by agreeing with another interpolation.

## 8. Spectrum and conditional microlevel diagnostic

Spectrum needs an explicitly selected contiguous fully supported rectangular grid; geometry selects it before observing values. No rectangle exists -> ineligible spectrum, not zero/inpainted holes. Subtract the declared mean; record Hann or rectangular window and its mean-square C2. For N=nx*ny and F=DFT(window*demeaned_grid), full two-sided bin power `P=|F|^2/(N^2*C2)` in nT^2. Its sum equals mean(window^2*demeaned_grid^2)/C2 within 1e-10 relative+1e-12 nT^2; with rectangular window this equals variance. Frequencies are fftfreq axes in cycles/m; multiply by 2*pi only for labelled rad/m views. No density units are claimed for bin power. Store directional sectors and exact removed/retained power; no power-to-depth conversion.

Conditional microlevel diagnostic assumes nearly parallel acquisition lines and explicit common grid support. Let flight azimuth alpha, along-direction wavenumber k_parallel and cross-direction k_perp. A stripe-removal transfer is `H=(|k_perp|^4/sqrt(|k_perp|^8+kc^8))*exp(-(k_parallel/ka)^2)`, with zero-mode H=0 and positive kc,ka supplied in rad/m. Removed=IFFT(H*F), retained=original-removed. Preserve transfer and removed grid; there is no automatic promotion or point correction. This is a reviewed concrete directional high-pass/along-line suppression model, not a claim to reproduce Charleston's contractor filter. Nonparallel/missing-support cases are ineligible. A genuine geological signal varying across lines and invariant along them has the same directional signature and will be attenuated: the parallel-geology negative control must expose that loss, not claim universal geological preservation. A user-requested amplitude cap is an additional explicit diagnostic clipping operation with its own spectrum, never a guessed field uncertainty.

## 9. Original recorded-acquisition synthetic family

Prospective generator tests/fixtures/magnetic_lines/generate.py emits CSV, sidecar, truth-at-row/grid arrays and a deterministic manifest. It authors acquisition records, not a provider-looking grid resampled into lines. Base geometry: eight east-west flight lines at northings [-1400,-950,-520,-170,230,610,1050,1500] m, each 33 positions spanning easting -1600..1600 m, alternating direction; three north-south ties at eastings [-1100,0,1000] m, each 33 positions spanning northing -1600..1600 m. Total 363 records, 11 line IDs, 352 possible consecutive segments. One sensor. Fixed seed 20261003 adds recorded XY jitter bounded +/-5 m and upward heights 80+15*sin(ordinal/5)+10*cos(line_index) m in an authored engineering datum. Times start at synthetic 2001-01-01T00:00:00Z at 0.5 s per sample with 120 s interline gaps. These timestamps/heights are authored control parameters, never Charleston/Bartlett facts.

Truth is the sum of three independently computed magnetic dipoles at local (e,n,u)=(0,0,-300),(-700,500,-500),(800,-600,-250) m with moments (2e7,-1e7,3e7),(-1e7,2e7,1e7),(1e7,1e7,-2e7) A*m^2. Direct SI formula is `b=(mu0/(4*pi))*[3*r*(m dot r)/|r|^5 - m/|r|^3]`, then tesla to nT by 1e9; mu0 is explicitly 4*pi*1e-7 N/A^2 for this analytic control definition, not a precision metrology assertion. Project onto authored F=48,000 nT, D=12 degrees east, I=55 degrees down. Nonparallel moments intentionally include remanent-like orientations, without asserting actual remanence. True generating dipoles are not the fitted equivalent-source geometry, preventing that inverse crime. Compare direct vector formula with pinned Harmonica dipole_magnetic at independent coordinates; oracle tolerances in validation.

Six separately hashed regimes reuse recorded XY/identity but have explicit differences: S1 dipole baseline/no error; S2 exact planar crossover calibration with known flight offsets and tie gauge; S3 independently authored navigation lag + base perturbation + heading calibration, with clocks and calibration inputs; S4 interior gaps, duplicates, mixed/missing height/clock metadata as explicit derivatives; S5 added 150 m cross-line sinusoid that violates line sampling support; S6 added smooth true cross-line geology plus stripes, showing microlevel ambiguity. Each regime describes every injected term and any sigma as an authored stochastic parameter, never a field estimate. S2 replaces upward heights by authored common 80 m and scalar truth by `10+0.002*e-0.003*n` nT, so segment interpolation is exactly compatible at crossings; offsets are `2*(line_index-3)` nT for flights and zero for ties. Its exact gauge check is distinct from dipole-field crossovers, whose interpolation/height mismatch must not be absorbed as offset truth. S3 base perturbation is 3*sin(2*pi*t/120) nT, heading ac=2/as=-1/a0=0 nT and tau=+0.25 s. Its supplied base samples include every measurement UTC; navigation oracle truth is explicitly the same authored piecewise-linear path evaluated at t+tau, avoiding an incorrect exact-recovery promise for undersampled nonlinear calibration. Fixed authored noise, if used, has seed/standard deviation and a separately saved noise-free truth; baseline has none.

Independent plane, null, single-periodic-mode and endpoint/intersection controls complement this family. Wrong-unit, swapped-axis, sign/datum/reference, unsigned lag, wrong correction state, rank deficiency, height-mismatched crossovers, sealed-data leakage, spectrum holes, duplicate keys, overbounds, unknown rights and RTP are named negative controls, not intentionally failing assertions. Positive acceptance is never obtained by relabelling these as unsupported after fitting or by replacing field evidence with S1.

## 10. Metrics and replay

For eligible outer samples residual r=observed-predicted: count, coverage, bias mean(r), RMSE sqrt(mean(r^2)), MAE mean(abs(r)), median absolute error, max absolute error and per-line metrics, all nT. Show ties/flight/sensors/height strata separately. No R-squared when variance is zero; no standardized metric without admitted uncertainty. Report candidate/fold failures and matched-support comparator differences. Field thresholds must be predeclared from independently justified objective/measurement evidence; none is invented here. If such evidence is absent, numerical metrics are reported as unresolved field acceptance rather than a claimed pass.

Provider comparison requires verified numeric nT grid, same scalar channel/processing/reference/datum, coordinate transform and compatible plane, plus documented grid registration. Compare matched supported nodes with residual distributions; do not extract numbers from Charleston RGB pixels. Bartlett 200 m compiled grid can supply negative-kind/regional context only; no trace/crossover/flight uncertainty is synthesized. Exact replay validates request/schema/source/environment pins, row/array/mask identities, objective and tolerances; no overwrite or network retrieval in replay. Export allowed members and record every denied member/reason.
