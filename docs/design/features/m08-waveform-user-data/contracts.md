# Exact local waveform inputs, QC and result contracts

Status: PROPOSED, not a wire/API schema or implemented parser. Fixed literals below require full Main approval before code. All intervals in this lane are half-open. Standards inform parsing; stricter lane limits below are proposed product policies, not universal format limits. [SEED 2.4](https://www.fdsn.org/pdf/SEEDManual_V2.4.pdf) and [StationXML](https://docs.fdsn.org/projects/stationxml/en/latest/reference.html) are the primary format references.

## 1. Raw inputs and preallocation limits

Inclusive bounds; reject cap+1 before allocating the corresponding native tree/decoded array. Whole-file counters apply even to records outside the requested analysis subwindow.

| Quantity | Fixed proposed limit/policy |
| --- | --- |
| MiniSEED exact raw bytes | 1..16777216 bytes; no archive/compressed outer wrapper |
| StationXML exact raw bytes | 1..2097152 bytes, strict UTF-8, no BOM, DTD/entity declarations/XInclude/external retrieval |
| Request JSON local file | 1..65536 bytes, UTF-8/no BOM, decoded duplicate keys forbidden, finite native numbers, no bool-as-number; depth8/nodes4096/key64/value2048 UTF-8 bytes |
| Request scientific identity | Compact sorted CPython ASCII canonical<=65536 bytes, pre-counted before copy/serialization/hash; this is NOT the original JSON byte hash |
| Waveform scope | One exact network/station; 1..3 unique channel+location identities, all named in request; no extra channels or stations hidden in file |
| Data records | At most4096; record length a power of two256..4096; one required blockette1000, optional single1001; other blockette kinds unsupported |
| Sample encoding | MiniSEED2 codes1(int16),3(int32),10(STEIM1),11(STEIM2), integer counts only; quality D/R/Q/M preserved without treating it as calibration |
| Samples | Each record1..65535; each channel at most60000; overall declared/decoded samples at most180000, including outside analysis subwindow |
| Rates | Exact integer Hz in {20,40,50,100,200}, one common rate for selected channels; no blockette100 float-rate override |
| Time extent | Conditioning window10..300 seconds; analysis interval at least5 s, inside conditioning interval and final edge-valid region; sample-aligned endpoints |
| XML preflight | Depth32; elements50000; total attributes100000; at most16 attributes/element; name128 UTF-8 bytes; individual attribute/text token8192 bytes; total decoded text1048576 bytes |
| Inventory semantics | At most8 networks,32 stations,64 channel epochs; selected station response stages1..32; each FIR/coefficient list at most4096, each pole/zero list at most128; overall response scalar coefficients20000 |
| Response work | W=sum over selected channels of `(Kfft/2+1)*(1+sum over its stages of (1+pole_count+zero_count+numerator_count+denominator_count+fir_count))`, at most20000000 integer bin-coefficient units; reject over before evalresp |
| Derived output | At most33554432 bytes; JSON metadata at most2097152; no raw originals in output, no compression/archive or object-dtype arrays |

Raw identity is SHA-256 of actual received bytes and measured length. Decoder normalization never changes this identity. The supplied provider identity is a separate declaration. File paths stay local to the CLI and are not stored in scientific output or safe errors. Library reads receive the very preflighted bytes, never a URL or a reopened mutable file.

The MiniSEED scanner verifies full record boundaries, header endian interpretation (reject ambiguity), six-digit sequence field, fixed-header reserved bytes, valid calendar/ordinal-day fields, offset ranges, acyclic nonoverlapping blockette chains and exactly specified counts. For int encodings, verify count*width fits actual payload; for STEIM, validate64-byte frame alignment/control-word capacities before decode, then enforce exact decoded npts and X0/Xn consistency. Fixed header word order and blockette1000 sample word order are separately checked. Do not trust an engine's `headonly` result as the preallocation proof. A declared sample budget that fits but has malformed compression can still fail native decoding; child isolation contains that failure, not a claim that the scanner verifies every STEIM sample before reading it.

Fixed-header byte offsets are zero-based relative to each original record: sequence0..5, quality6, reserved7, station8..12, location13..14, channel15..17, network18..19, year20..21, ordinal day22..23, hour24, minute25, second26, reserved27, 0.0001-second fraction28..29, npts30..31, signed rate factor32..33, signed rate multiplier34..35, activity36, I/O-clock37, quality flags38, blockette count39, signed time correction40..43, data offset44..45 and first-blockette offset46..47. Identifiers allow only right space padding and must match requested NSLC after that padding removal. Reserved bytes7 and27 are ASCII space and zero respectively. Require a unique big/little-endian interpretation satisfying all header/date/offset/blockette constraints; sample word order is separately declared by1000. Sequence is six decimal ASCII digits retained as text, not monotonic identity. Fraction<=9999, hour<=23, minute<=59, second<=59 and actual Gregorian day range are required; leap flags remain unsupported.

Nonzero signed factor F and multiplier M define rational Hz as `(F if F>0 else -1/F)*(M if M>0 else -1/M)`; reduce exactly then require an allowed integer rate. Blockette1000 is8 bytes: type,next,encoding,word_order,record_exponent,reserved; word_order0/1, exponent8..12, reserved0. Blockette1001 is8 bytes: type,next,timing_quality0..100,signed microseconds,reserved0,frame_count. Its frame_count is0 (unknown) or no larger than the actual STEIM payload frame count; integer encodings require0. Blockette count1/2 equals the visited chain; offsets>=48, each blockette ends before data_offset, and only the last next-offset is0. Integer width*npts must fit payload. STEIM data_offset and payload length are multiples of64; check packed coding capacities and X0/Xn positions according to encoding/word order before the native call. Native decoding is one record per call and must return exactly one matching trace with exact npts and int16/int32 values in int32 range. No float-to-int repair; identity/rate/time/count disagreement is `waveform_decode`.

The XML scanner is event-only, with bounded names/text/counters and no inventory tree. DTD/entity declaration rejection happens at parser declaration events, not substring search; external handlers never resolve references. Semantic epoch/stage validation precedes `read_inventory(BytesIO(...), format='STATIONXML')`. Ignore inert descriptive extensions only within byte/node bounds; reject scientific response extensions or namespace ambiguity. Do not perform remote XSD validation. Record schemaVersion1.1 or1.2; other versions unsupported.

Use strict incremental UTF-8 plus Expat events on chunks<=4096 bytes. Reject BOM, invalid UTF-8/surrogates, document type/entity declarations, parameter/external entities and XInclude in any namespace before inventory construction. Predefined entities/numeric references are allowed and counted after decoding. Expanded names/attributes and accumulated character callbacks count by decoded UTF-8 bytes across each complete text token. Root must be exactly `{http://www.fdsn.org/xml/station/1}FDSNStationXML`; schemaLocation is inert. Retain only bounded typed scientific descriptors and nested epoch/identity tables, not a generic XML tree. Descriptive extension elements/attributes may occur only in a different namespace outside Response/Stage and selected scientific identity/epoch/unit/orientation/rate fields; they still count toward all limits. Unknown core scientific tags, duplicate scalar fields or extension overrides reject. No remote XSD.

Compute W after bounded descriptor parsing and N/K determination but before native response evaluation/frequency-vector construction. W is a work surrogate, not measured CPU or a heap guarantee. The byte/sample/XML caps still precede their corresponding constructions. Request/reference JSON uses bounded token grammar before tree construction, decoded duplicate/surrogate rejection, numeric lexeme<=128 bytes and integer TOKEN within +/-9007199254740991. Preserve CPython native finite float semantics, including fractional/exponent underflow and signed float zero; reject overflow/nonfinite and bool-as-number, not repair or reserialize original bytes.

## 2. Request: `caos.local-waveform-request.v1`

Exactly these root keys: `schema`, `channels`, `conditioning_start_utc`, `conditioning_end_utc`, `analysis_start_utc`, `analysis_end_utc`, `representation`, `source`, `adc_rails`, `processing`. Unknown/missing keys reject. Native entry point validates dict keys/types/finite values as well as CLI's bounded JSON grammar; no coercion or defaults.

- `schema`: literal `caos.local-waveform-request.v1`.
- `channels`: ordered list1..3 of exact objects `{network, station, location, channel}`. SEED2 uppercase ASCII network1..2, station1..5, location0..2, channel exactly3 alphanumeric characters. Empty location is `""`, never `"--"` inside this contract. It is not inferred from channel suffix or file name.
- Four UTC strings: real ISO Gregorian dates with `Z`, up to6 fractional digits; years1970..2100, seconds00..59. Preserve supplied strings and exact normalized integer microseconds separately. No local timezone, leap-second parsing or float Unix time. All channels must fully cover the conditioning interval on a common sample grid. Whole-record samples outside it still count against every input/decode limit and remain in the raw counts/record table; their explicit `conditioning_slice` is recorded, not silently discarded or processed with the wrong epoch.
- `representation`: literal `unrestituted_integer_counts`. Already response-corrected/normalized/floating traces reject this lane even if units are declared counts.
- `source`: exact `{kind, citation, provider_url, declared_sha256, rights, processing_statement}`. Kind `user` or `provider`; citation and processing_statement nonempty bounded strings; provider_url null or inert HTTPS citation, never a fetch instruction; declared_sha256 null or64 lowercase hex, if supplied must equal measured MiniSEED hash. Rights `private-use-attested`, `reviewed-public-scsn`, `unknown`, `forbidden`; unknown/forbidden cannot enter scientific computation. The public-SCSN choice requires the separate reviewed per-object receipt, not a user enum alone. Helper reports declaration, not provider authentication. Text declares no prior response removal/resampling/rotation; actual byte tests remain required.
- `adc_rails`: channel-order list of null or exact `{minimum_count, maximum_count, evidence}`. Integers bounded to int32 and minimum<maximum; evidence nonempty. Null means actual converter rails unknown, not int32 full-scale or proven unclipped.
- `processing`: exact keys in the following table; all must be supplied. Quantities in seconds/Hz, no bool numeric.

| Key | Allowed value and meaning |
| --- | --- |
| `output` | `native` only; XML native displacement/velocity/acceleration selects DISP/VEL/ACC respectively |
| `prefilter_hz` | Four finite numbers0<f1<f2<f3<f4<fs/2; require f1>=0.05 Hz and at least three FFT bins in each flank and plateau |
| `water_level_db` | null (exact supported nonzero inverse) or finite20..120 dB magnitude floor; submitted unchanged |
| `taper_fraction` | Finite0.01..0.10, full two-end fraction, not fraction per end |
| `bandpass_hz` | Two finite numbers f2<=lo<hi<=f3, hi<0.45fs; no inferred regional passband |
| `filter_order` | Exact integer2..6 Butterworth prototype order; resulting bandpass order is twice this |
| `filter_mode` | `offline-zero-phase` only; acausal SOS forward/backward, explicit odd extension |
| `edge_guard_s` | Finite0..150 submitted guard, then effective guard is the maximum in algorithms.md; no claim universal transient elimination |
| `sta_s`, `lta_s` | Finite0.05..2 and0.5..20 respectively, sta<lta; mapped by ceiling to sample counts, 2<=S<L; N>=3L |
| `threshold_on`, `threshold_off` | Finite1<off<on<=100; exact strict on/off semantics in algorithms.md |
| `refractory_s` | Finite0..10, mapped by ceiling to samples; applied after interval closure |
| `welch_segment_samples` | Integer power of two64..8192, no larger than edge-valid analysis sample count; no library auto-shortening |

No labels/catalogue times enter this request. Fixed epoch/gain/error rules cannot be relaxed by a submitted knob. A changed request always makes a new request identity/result; an existing result is immutable.

Seconds-to-window mapping is literally CPython `ceil(value*fs)` on the admitted native numeric value; preserve submitted int/float types, do not round toward an intended decimal or apply epsilon. UTC/sample-grid calculations remain exact integer microseconds and are separate from those floating processing knobs. Native request validation walks only exact dict/list/str/int/float/null types within the same counters before copying; subclasses, custom iterables/number hooks, cycles, surrogate strings or excessive tokens reject. No shared global JSON settings or change to the physical-JSON helper.

## 3. Time, continuity, orientation and response QC

For record start, apply header correction in100 microsecond units exactly once according to activity bit1, then signed1001 microsecond offset. Rational sample index time is `start_us + i*1000000/fs`; with supported rates this is an exact integer microsecond grid. Chronologically consecutive segments must satisfy `next_start = previous_start + npts*1000000/fs`. Any gap/overlap, including an identical duplicated record, remains explicit and ineligible; no rounding to hide it. Rate changes or between-channel grid/start/end disagreements are ineligible. Leap/calibration/time-questionable/padded/clipped/saturated/telemetry/filter-charging flags are retained and block physical processing. Spike/glitch flags also block this first lane. Clock-locked flag and timing quality are evidence fields, not assumed uncertainty; absent lock or1001 yields `absolute_timing_verified=false` warning, never fabricated accuracy.

`absolute_timing_verified` is ALWAYS false in this unit: no independent clock calibration input exists. Clock lock/1001 quality may supply `clock_flags_consistent=true`, never measured UTC accuracy or timing sigma. Activity calibration bit0, leap bits4/5, any data-quality bit0..7, I/O-clock parity bit0 or long/short-record bits1/2 are blocking conditioning flags. Activity trigger bits2/3 and event-progress bit6, I/O start/end-series bits3/4 are retained informational flags; clock-lock bit5 is evidence only. Reserved activity/I/O bits must be zero or structurally unsupported. This table is a conservative lane policy, not a declaration that every flagged format record is malformed.

Native integer counts are preserved. Clipping/flag QC for physical eligibility applies to all records/samples contributing to the conditioning interval; outside samples have separate diagnostic flags, never clearance transferred to the selected window. A supplied ADC rail reached/exceeded or header clipping/saturation is `clip_detected`; an extreme-value plateau of at least3 identical samples is `clip_suspected`, even without known rails. Constant entire conditioning channel is `flat`. These block physical/pick processing. With no such evidence, `clipping_status=not_detected` if rails are supplied, otherwise `unknown`; neither establishes absence of all clipping. Unknown rails may allow conditional processing with an explicit warning, not an unclipped-field claim. Reject sign manipulation, missing-channel duplication and guessed axis labels.

Plateaus mean runs at the conditioning channel's actual global minimum or maximum, not every repeated interior sample. One selected measured channel is valid; requested but absent channels are QC-only, with no invented ENZ components. Whole-record continuity/rate/identity defects block this first lane even outside the slice; outside-only clipping/quality flags remain separate diagnostics.

XML join is nested `(Network.code, Station.code, Channel.locationCode, Channel.code)`, not independent name sets. Require exactly one channel epoch whose intersection with station/network epochs covers the entire conditioning interval. This lane conservatively uses `[startDate,endDate)`; a missing endDate is open-ended, a missing startDate is insufficient for selected channels. Ambiguous overlaps, wrong parent/network/location, partial coverage and an epoch crossing are QC-only. Never select the first match, split/relabel epochs, truncate a requested window or attach a current response to2019 bytes.

Selected channel requires finite azimuth/dip in their FDSN ranges, finite position/elevation/depth and explicit rate matching waveform rate. Preserve source coordinate datum if present, otherwise `unknown`; no distance/location/geoid calculation uses it. Azimuth/dip define a channel-native unit projection on geographic E,N,up; channel suffix Z/1/2 alone cannot prove ENZ. No rotation is performed. Full response requires linear stages1..K without gaps/duplicates, finite gain>0 and gain-frequency>0, compatible adjacent stage units, valid finite PZ/FIR/digital coefficients/decimation and final count units. Supported native first units are the explicit aliases `M`/`m`, `M/S`/`m/s`/`M/SEC`, and `M/S**2`/`m/s2`/`M/SEC**2`/`M/(S**2)`/`M/S/S`; preserve original unit spellings. Only exact SI metres, not nm/cm/mm, pressure/volts/strain or guessed aliases, enter this lane.

Sensitivity>0, sensitivity frequency in(0,Nyquist), units consistent with first/last stage; at that frequency require relative full-chain magnitude mismatch<=0.05. This fixed proposed consistency rule is not a5% calibration uncertainty. Reject/retain any native engine response warning, polynomial/response-list/unknown stage, zero/nonfinite response in the nonzero prefilter support, or coefficient/sampling-chain inconsistency. Supported stage subset: analogue PZ in radians/s or Hz, digital PZ, FIR, digital numerator/denominator coefficients, and scalar gain stages with fully declared units. Check decimation chain rates/factors/offsets and explicit delay/correction; retain their effective phase, never silently remove them. Full transfer operator and this consistency metric appear in the result.

Selected latitude[-90,90], longitude[-180,180], finite elevation/depth in metres, azimuth[0,360), dip[-90,90] are required. No vertical-datum clearance follows. Native alias maps exactly to `m`, `m/s` or `m/s2`; final count aliases only `COUNTS`, `counts`, `COUNT`. Adjacent internal unit names must match case-normalized literals without dimensional guessing. Gain-only stages with insufficient declared units remain `response_units_missing` QC-only; do not accept library inference. Require numbering1..K, finite normalization>0 and normalization/gain frequencies inside applicable Nyquist. Analogue right-half-plane poles and digital poles on/outside the unit circle are unsupported; evaluated support poles/zeros and nonfinite operators are checked explicitly. Digital decimation factor is a positive integer, offset0..factor-1; declared rates reproduce the next stage/final waveform rate. Delay/correction are finite seconds, retained with actual engine phase convention. FIR symmetry is NONE/ODD/EVEN. Analogue coefficient stages and undocumented variants are excluded.

For water_level_db=null, the pinned engine reciprocates ALL non-DC H bins, including those where T=0. Require finite nonzero H and finite1/H there; otherwise QC-only `response_inverse_undefined`, not ignored0*infinity. With finite floor, zero H outside support is allowed with inverse0; zero H anywhere T>0 remains QC-only. No warning suppression or nan-to-zero repair.

Every coefficient is finite real and every nonreal pole/zero has its exact complex-conjugate partner with equal multiplicity after native numeric parsing; no pairing tolerance or synthesized conjugate. This lane requires a real-valued sensor transfer function, rather than silently letting IRFFT invent the missing negative-frequency response. Retain an unmatched pair as `response_chain_inconsistent` QC-only. Malformed numeric grammar is instead rejected before any inventory/response call.

## 4. Result: `caos.local-waveform-result.v1`

Terminal classification is fixed: wrong builtin types, raw/counter bounds, malformed grammar/headers/STEIM mismatch, unknown encodings/rates/leap time model, forbidden blockette/schema versions or invalid request/analysis bounds are `rejected` with the fixed input error. Parseable conditioning quality flags, gaps/overlaps, missing requested channels, incomplete/ambiguous response, orientation/unit/response warning/floor failures are `qc_only`. Unknown/forbidden local rights are checked before native decode and give `qc_only`/`rights_ineligible` with no decoded/physical array; approved public-SCSN is an external reviewed declaration, never something this helper authenticates. Structural scanning/hash alone is not an observation dataset. Missing/incompatible engine is `engine_unavailable`. Unexpected native child exit is `failed`; nonfinite numerical arrays/CF are `failed`/`numerical_failed`. Output overflow, cancellation and deadline are `resource_exceeded`, `cancelled`, `timed_out`. No terminal failure is recast as a successfully computed empty result.

Type/raw/grammar checks precede engine availability. For a structurally valid but rights-ineligible source, retain that QC receipt without importing a scientific engine; do not diagnose a missing engine as observed field failure. Other raw QC requiring decoded samples remains UNRESOLVED if its actual decoder is unavailable. Selecting a public rights enum is only a local-use declaration: the independently retained operator/Main per-object review is REQUIRED for the original-case/publication gate, and cannot be certified by this ordinary function. Source/unit/response consistency is never waived by rights acceptance.

Core `WaveformResult` has exactly `metadata` (native finite dict) and `arrays` (owned read-only NumPy arrays). Metadata root keys: `schema`, `method`, `status`, `sources`, `request`, `engines`, `channels`, `processing`, `qc`, `candidates`, `acceptance`, `field_truth`, `array_descriptors`. Schema/method fixed as above. Output manifest adds `metadata_sha256` and `execution_receipt`; no source filename/private path/user identity is exported.

`sources` contains separately measured MiniSEED and XML `{raw_bytes, raw_sha256, declaration}`; request contains original submitted values and its native scientific identity. Request dialect is CPython sorted compact ASCII JSON, `ensure_ascii=True`, `allow_nan=False`; preserve int versus float and signed float zero. Original CLI request-file bytes/hash are a separate identity. Never use a JS round-trip or relabel hashes between domains. Receipt pins source code bytes, submitted request and derived binary bytes, not a digest-only scientific validity assertion.

`channels` retains ordered NSLC, actual start/rate/npts, exact per-record original byte offset/length/sample interval, clock flags/time correction, XML epoch bounds/stage identity, SI native quantity, azimuth/dip projection, original versus normalized unit literals, ADC evidence and all QC reasons. Mixed native quantities remain separate channels; no mixed-unit station energy.

| Array per channel (C<=3) | Shape / dtype / unit / presence |
| --- | --- |
| `counts` | [Nc], int32, counts; accepted decode only, actual chronological segments with record table, no fill |
| `physical_native` | [N], float64, m or m/s or m/s2; computed only, conditional band-limited response estimate |
| `filtered_native` | [N], float64, same SI unit; computed only, acausal offline filtered signal |
| `edge_valid` | [N], bool, dimensionless; computed only, mathematical processing mask, not field-quality probability |
| `time_taper` | [N], float64, dimensionless; computed only |
| `response_frequency_hz` | [Kfft/2+1], float64, Hz |
| `response_real`, `response_imag` | same frequency shape, float64, counts per native SI unit |
| `inverse_real`, `inverse_imag` | same frequency shape, float64, native SI unit per count; floor audited |
| `prefilter_weight` | same frequency shape, float64, dimensionless |
| `characteristic` | [N], float64, dimensionless, no calibrated probability |
| `psd_frequency_hz` | [M/2+1], float64, Hz; M=Welch segment length |
| `counts_psd`, `physical_psd`, `filtered_psd` | [M/2+1], float64, counts2/Hz or native-unit2/Hz, explicitly named; computed only |
| `filter_sos` | [filter_order,6], float64, normalized digital coefficients |

No full [C,N,K] intermediate cube is retained. PSD is calculated on the same edge-valid analysis interval for all representations. Metadata retains segment count, omitted tail, window normalization, discrete integral/RMS and valid interval. Candidate row exact keys: `channel_index`, `on_index`, `off_exclusive_index`, `peak_index`, `peak_ratio`, `on_utc`, `on_relative_s`, `truncated_at_valid_start`, `truncated_at_valid_end`, `phase`, `timing_sigma_s`; phase/sigma null. Indices refer to the conditioning array and relative seconds to its start, not an unrecorded crop origin. The truncation flags concern the edge-valid requested analysis interval. Absolute times refer to source clock, with timing-verified flag, not calibrated onset truth. Zero candidates is legitimate `computed`, not a fake arrival. At most4096 intervals overall; overflow produces `resource_exceeded`, never silently truncates the catalogue.

QC-only retains available counts/segment diagnostics and source/QC metadata, with all physical/filtered/response/PSD/candidate products absent (not zeros or empty simulated arrays). Malformed undecodable input retains only safe measured hash/size receipt if CLI has bounded original bytes; it must not call that an observation dataset. All acceptance flags `field_eligible`, `method_accepted`, `host_admitted`, `provider_verified` are false. `field_truth=null` always. JSON never contains NaN,Infinity or private exception text.

## 5. Safe errors and separately sealed evaluation

`WaveformInputError(code, field, message)` uses fixed codes: `waveform_type`, `waveform_limit`, `waveform_format`, `waveform_contract`, `waveform_decode`, `waveform_engine`. Field is a known schema path or `document`, never an input value. CLI exceptions yield fixed failure records without native stderr/warnings, tracebacks, causes, locals, tokens, absolute paths or private samples. Private diagnostic stderr may be retained outside the public artifact; unexpected native exits are `failed`, not safe-parser rejection or zero resources. Decoder byte/private context must not be chained into public errors.

Fixed messages respectively: `Waveform input type is unsupported`, `Waveform input exceeds the local limit`, `Waveform encoding is unsupported or malformed`, `Waveform scientific request is invalid`, `Waveform samples could not be decoded`, `Waveform scientific engine is unavailable or incompatible`. Parser error application fields are only those fixed code/field/message strings; recognized caught exceptions are converted to the fixed code and raised outside handlers so __cause__/__context__ are null in direct calls. Traceback locals are not a safe public payload. QC reason registry is separate: `rights_ineligible`, `unsupported_clock`, `gap`, `overlap`, `rate_mismatch`, `missing_channel`, `epoch_missing`, `epoch_ambiguous`, `epoch_partial`, `orientation_missing`, `response_units_missing`, `response_stage_unsupported`, `response_chain_inconsistent`, `response_sensitivity_inconsistent`, `response_warning`, `response_zero_support`, `response_inverse_undefined`, `flat`, `clip_detected`, `clip_suspected`, `blocking_flags`. Warnings only `adc_rails_unknown`, `clock_accuracy_unknown`, `datum_unknown`, `zero_filtered_signal`. Sort reasons by this registry order, then channel index, not discovery/native warning order. Any computed array nonfinite/invalid yields failed `numerical_failed`; no uncertainty repair.
