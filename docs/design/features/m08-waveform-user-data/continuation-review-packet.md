# M08 local scientific completion boundaries

The ordinary method calculates raw QC, conditional full-response native motion, explicit offline filter, PSD and unlabelled onset candidates. Parameter-effect and independent same-input controls distinguish authored signals from real preselected held-out traces; neither establishes field truth or calibrated uncertainty.

Original Ridgecrest failures are retained unchanged. The intrinsic contract adds explicit provider format support, transparent bounded unit provenance, independent DC/phase controls and a named cloud catalogue variant. Exact HNZ evaluation has no source reference; another component cannot replace it.

The complete feature includes strict file/export/CLI and actual cold-resource/platform gates. Ordinary science or mocked supervisor tests cannot close those gates. No reduced application, host activation, production/profile acceptance, auth/admin/backup work or M13/cohort mutation follows from a local calculation. Runtime, diagnostic and reviewer execution details are private.
