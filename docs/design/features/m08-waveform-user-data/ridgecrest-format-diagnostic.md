# Ridgecrest provider representation semantics

The original StationXML declares ISO-8859-1; the prior UTF-8-only lane rejected that declaration as waveform_format/document before waveform decoding. XML1.0 permits the declared encoding. This is a transport-policy mismatch, not proof that the provider XML is malformed. The original validates against the official FDSN StationXML1.1 schema; schema validity is not calibration or physical eligibility. See [XML encoding](https://www.w3.org/TR/xml/#charencoding) and [StationXML1.1](https://www.fdsn.org/xml/station/fdsn-station-1.1.xsd).

Selected CI.GSC..HNZ Stage2 contains only StageGain Value1/Frequency0.03Hz, with no provider-declared units. Neighbour boundaries explicitly declare V and V. Stage4 is FIR COUNTS-to-COUNTS with StageGain Frequency0Hz; Delay and Correction are different original values and must not be equalized. Gain-only filters are optional in the standard, and Frequency is not universally restricted to positive values. The intrinsic contract admits only its exact transparent interior-unity case and finite/nonzero FIR DC normalization, with visible original-null/derived-effective unit provenance and an independent full complex/phase oracle. No source XML rewriting or generic missing-unit inference. [FDSN Stage semantics](https://docs.fdsn.org/projects/stationxml/en/latest/reference.html#stage).

The retained cloud phase header has ten fields: event type eq and geographic type l are separate. The legacy adapter requires nine fields and rejects it as waveform_format/document. The2007 STP manual documents nine fields; current SCEDC catalogue descriptions distinguish event and geographic type. A named cloud10 converter is separate from legacy9; no silent token dropping or column shift. [SCEDC cloud archive](https://scedc.caltech.edu/data/cloud.html#event-phases), [catalogue types](https://scedc.caltech.edu/eq-catalogs/catalog-search-help.html), [STP manual](https://scedc.caltech.edu/data/stp/STP_Manual_v1.01.pdf).

The original phase file has95 thirteen-field arrivals,79 P and16 S. Its sole CI.GSC pick is HHZ/P, not HNZ. Exact CI.GSC..HNZ has zero reference rows, so evaluation remains not_evaluable after correct format support. No component reassignment, origin shift, changed window or label-driven tuning is permitted. Source quality is ordinal, not calibrated Gaussian sigma. All original bytes and historical rejection seals remain unchanged; parsing these representations is not a positive physical field result.

Operational diagnostics, source-retrieval receipts, machine paths and runtime inventories are maintained privately. Public originals/field arrays remain unpublished. [Contract](intrinsic-amendment.md) and [validation](intrinsic-validation.md) define the bounded scientific treatment.
