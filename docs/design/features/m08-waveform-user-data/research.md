## 1. Waveform representation and clock

[FDSN SEED 2.4](https://www.fdsn.org/pdf/SEEDManual_V2.4.pdf), chapter 8 (printed pp. 108-110, 123-124), defines record sample count, signed rate factors, clock/data-quality flags, blockette 1000 encoding/record size, and blockette 1001 timing fields. A time correction is applied only if not already applied; blockette 1001 contributes a signed microsecond offset. Timing-quality percentages are vendor-specific, not a measured Gaussian clock error. A filename or `Q` quality indicator is not proof of calibration or unclipped samples. The proposed supported subset is MiniSEED 2 integer counts; [MiniSEED 3](https://docs.fdsn.org/projects/miniseed3/en/latest/definition.html) remains explicitly unsupported. No format sniffing followed by unrestricted whole-file native decode.

Decision: exact NSLC identities, rational sample grids and record-by-record allocation checks precede decoding. Gaps, overlaps, rate changes, padding and questionable timing are retained QC failures, never interpolation, zero-fill or hidden merging. Leap-second records require a separate supported time model and are excluded here. Bounds, encoding subset and timing policy are literal in [contracts](contracts.md).

## 2. Response, orientation and calibration

[StationXML reference](https://docs.fdsn.org/projects/stationxml/en/latest/reference.html) supplies hierarchical network/station/channel epochs, response units, gains and orientation; azimuth is clockwise from true north and dip is positive downward from horizontal. [Response guidance](https://docs.fdsn.org/projects/stationxml/en/latest/response.html) distinguishes sensor/analogue/digitizer stages from total sensitivity. A counts declaration or dividing by sensitivity alone does not establish full response removal. Decision: select exactly one nested epoch over the entire conditioning window, validate the complete linear stage chain, and retain channel-native projections. No inferred ENZ, datum, polarity flip or horizontal rotation.

The reviewed [ObsPy 1.4.2 response implementation](https://raw.githubusercontent.com/obspy/obspy/1.4.2/obspy/core/trace.py) mutates a trace, resolves inventory response at trace start, pads its FFT and has special polynomial handling. Our proposed adapter will use a private copy with an already uniquely selected linear response and independently check full-window coverage; it will reject polynomial responses rather than accept an assumed gain. [Current removal documentation](https://docs.obspy.org/packages/autogen/obspy.core.trace.Trace.remove_response.html) warns that water-level suppression depends on requested quantity. This lane chooses only the instrument's native SI motion quantity and records the full prefilter/inverse operator. It estimates band-limited motion conditional on the published response, not a new field calibration.

## 3. Signal conditioning and spectral meaning

[SciPy 1.15.2 Butterworth](https://docs.scipy.org/doc/scipy-1.15.2/reference/generated/scipy.signal.butter.html) and [SOS forward-backward filtering](https://docs.scipy.org/doc/scipy-1.15.2/reference/generated/scipy.signal.sosfiltfilt.html) support a stable, explicitly padded offline filter. Forward-backward filtering is acausal; a visible early onset cannot be claimed an unbiased real-time arrival. The proposed filter records coefficients, padding, effective squared magnitude response and a conservative edge mask, not a guarantee of universal transient removal.

[Welch's density contract, SciPy 1.15.2](https://docs.scipy.org/doc/scipy-1.15.2/reference/generated/scipy.signal.welch.html), gives units of input-unit squared per Hz, with explicit window/overlap/detrend/scaling choices. Decision: retain counts and corrected SI spectra separately, fixed periodic Hann, no spectral zero-padding, and an independent DFT/Parseval oracle. PSD is not amplitude spectrum, spectral resolution is not padded bin spacing, and band-limited RMS is not an instrument-independent earthquake magnitude.

## 4. Arrival detection versus phase identification

[Trnkoczy, amended 2011, NMSOP-2 IS 8.1](https://gfzpublic.gfz.de/pubman/item/item_43337_3/component/file_56122/IS_8.1_rev1.pdf), DOI [10.2312/GFZ.NMSOP-2_IS_8.1](https://doi.org/10.2312/GFZ.NMSOP-2_IS_8.1), discusses detector tradeoffs with noise, sensor and window settings; a trigger is not necessarily a network event or phase identification. The amended PDF was byte-retrieved for metadata, but this tool could not extract its text; the [older author-hosted 1999 version](https://gfzpublic.gfz.de/pubman/item/item_4097_4/component/file_4098/IS_8.1_rev1.pdf) supplied readable sections 1-4. The version distinction is retained, not relabelled.

The [pinned ObsPy classic STA/LTA](https://raw.githubusercontent.com/obspy/obspy/1.4.2/obspy/signal/trigger.py) uses squared amplitude and a tiny-value floor; this differs from both the absolute-amplitude pedagogical description and the repository's frozen fixed floor. Decision: new identifier, per-channel unlabelled hysteretic intervals, direct rolling-sum oracle, no automatic first=P/second=S. Analyst references enter only a separate evaluator after predictions are sealed. A catalogue match is analyst agreement; missing uncertainty stays null.

[PhaseNet](https://arxiv.org/abs/1803.03211), DOI [10.1093/gji/ggy423](https://doi.org/10.1093/gji/ggy423), motivates separate per-sample phase scores. [Munchmeyer et al.](https://arxiv.org/abs/2110.13671), DOI [10.1029/2021JB023499](https://doi.org/10.1029/2021JB023499), evaluates picker dependence on data domains. Neither paper licenses attaching a calibration claim to this repository's frozen model or transferring its held-out accuracy to response-corrected Ridgecrest data. The existing held-out result remains read-only; no training, re-export or M13 inference is proposed in this unit.

## 5. Real Ridgecrest case and rights

[SCEDC's cloud page](https://scedc.caltech.edu/data/cloud.html) publishes `event_waveforms/2019/2019_187/38457511.ms`, its corresponding phase object and CI StationXML examples. These are candidate original objects, not downloaded/eligible fixtures. Its 2020 Ridgecrest DAS SEG-Y dataset is a different acquisition and explicitly outside this unit. Whole-event files contain many channels and may exceed our local bounds; the case plan uses a separately bounded station/window request rather than silently loading the complete event archive.

The [SCEDC-managed AWS registry licence](https://registry.opendata.aws/southern-california-earthquakes/) grants specified non-exclusive public-SCSN data use, reproduction and display with attribution; it is not CC0 or an automatic licence for every network/dataset. [SCEDC citation policy](https://scedc.caltech.edu/about/citation.html) requires SCEDC DOI `10.7909/C3WD3xH1` and CI DOI `10.7914/SN/CI`, plus the appropriate DOI for non-CI data. Decision: CI-only candidate, per-object scope review, no redistribution until Main approves the actual asset rights receipt. Unclear or incompatible assets remain rights-ineligible without an invented positive substitute.

The [station service](https://service.scedc.caltech.edu/fdsnws/station/1/) supports `level=response`; [dataselect](https://service.scedc.caltech.edu/fdsnws/dataselect/1/) requests time windows; [availability](https://service.scedc.caltech.edu/fdsnws/availability/1/) is metadata, not a gap-free sample guarantee. [Event service](https://service.scedc.caltech.edu/fdsnws/event/1/) supports arrivals in QuakeML. SCEDC limits concurrent service downloads to three; the future acquisition plan uses one. No network request belongs in the calculation helper.
