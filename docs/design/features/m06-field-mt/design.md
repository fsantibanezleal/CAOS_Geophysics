# M06 measured MT source and eligibility design

## Source and execution boundary

The candidate is C15 from the [AusLAMP New South Wales survey](https://ausmt.auscope.org.au/surveys/auslamp-nsw-2016-21), attributed to Geoscience Australia and the survey authors in [Record 2020/011](https://doi.org/10.11636/Record.2020.011). AusMT states open access and CC BY 4.0 for this survey. The exact object is `https://ausmt.auscope.org.au/data/edi/auslamp-nsw-2016-21/C15.edi`, 23,021 bytes, SHA-256 `353953564964015c59eaaa0ce8f808ebec48af0d51c11759a14c21be00b20a8f`. The station product records the identical source hash, 35 periods, and an automated phase-tensor `1-D` class. These are provider claims to verify, not a proof of one-dimensional earth structure. The file is acquired only into ignored `data/downloads/` and its full QC receipt into ignored `data/raw/mt/`.

An entry in `data/source-ledger.json` pins the source. The existing allowlisted `manual` acquisition path verifies the exact bytes and creates an immutable raw receipt. The QC runner takes the pinned source ID, never an arbitrary URL. It parses the original EDI numeric blocks independently of `mt_metadata==1.0.10`, compares the two representations before any physical inference, then evaluates the 1D admission criteria. No user data, frontend, API, shared ingestion adapter, or canonical replay bundle is changed here. The general EDI ingestion adapter currently rejects this EDI dialect's remote-reference channels and free-text INFO; the standalone M06 admission check is therefore a deliberate separate local lane, not a claim that uploaded C15 can enter the API pipeline.

## Physical and error contract

The source EDI identifies EX/EY dipole endpoints and HX/HY plus remote RX/RY magnetic azimuths. Verify EX and HX are collinear, EY and HY are collinear, both horizontal pairs are orthogonal, every impedance/error block references the same ZROT, and all ZROT values are zero. Preserve this frame. A non-right-angle rotation would require component covariance absent from the file. Frequency is Hz; impedance is left in EDI-native units for the dimensionless eligibility test because the file does not itself assert an impedance-unit or time-sign convention. The sign ambiguity affects an absolute forward comparison and is an additional inverse gate, but not the zero-diagonal/antisymmetry null test.

For each frequency, the necessary isotropic 1D form is `Z = [[0,z],[-z,0]]`. Set `sigma_upper = sqrt(Z.VAR)` as a deliberately generous SD per real/imaginary component: if EDI variance is complex variance, the true per-part SD would be smaller by `sqrt(2)`. Use no independent-component covariance assumption to shrink the uncertainty of `Zxy+Zyx`; use the sum of the two marginal upper SDs. Each of the three two-real-component WRMS values across **all** original periods must be at most 3, matching the established M05 necessary screen. This threshold was set before the C15 fit question. Record the per-period normalized departures as well as the aggregates. Independently calculate `Phi = Re(Z)^(-1) Im(Z)` where `Re(Z)` is numerically nonsingular, the Caldwell phase-tensor skew beta, and normalized departure of Phi from a scalar matrix. The upstream phase-tensor class is retained as an attributed screening result; it cannot override a failed complex-tensor gate. Check the complex tensor's rotationally invariant distance to its nearest 1D antisymmetric form under an exact 90-degree signed permutation.

Tipper blocks are ancillary: check a shared missing mask and nonnegative finite variance at valid periods; report availability and magnitude. No tipper is fitted in a 1D solve. Do not assign a statistical confidence level to EDI variances without a documented covariance/noise model. No error floor is added after seeing the candidate.

## Admission, inverse, and negative control

The current C15 diagnostic is **ineligible**: the 1D component WRMS test fails even under the generous SD assumption. The local JSON receipt must therefore contain `inversion_performed=false`, `methods={}`, `truth=null`, and no observed/predicted residual claimed from a layered model. The ineligibility is about this field candidate, not about the validity of the independent synthetic layered recursion already in `electromagnetics.py`. The Clear Lake cl061 M05 QC-only finding remains untouched. C15's source sign, impedance-unit and variance conventions also require a documented resolution before any absolute resistivity estimate; the phase quadrant alone is insufficient authority.

If a later station clears the same predeclared gates, the separate inverse review must freeze a frequency holdout before tuning, use `electromagnetics.impedance` and bounded SciPy TRF with multiple starts, compare a halfspace trained on the same training periods, show every complex normalized residual, and sweep finite-layer thickness and beta without choosing a model on holdout. A sensitivity Jacobian and conditional perturbation intervals would be labelled by the assumed error law and fixed parameterization. Neither a small residual nor a narrow conditional interval is geological truth. That future code and receipt are **not** part of this candidate's ineligible branch.

1. Verify provider licence, station product, exact EDI bytes and ignored local raw receipt.
2. Establish raw/official parser equality, full tensor/rotation/error QC, phase tensor diagnostic, and the field negative verdict.
3. Run synthetic invariance and malformed-input tests, then re-acquire C15 and reproduce the ineligible receipt with the documented command.
4. Record requirement-level convergence, aggregate metrics, and remaining M06 gates. No inverse, PR, merge, or deployment is produced by this branch.
