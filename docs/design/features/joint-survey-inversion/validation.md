# Frozen prospective controls

No M11 numerical acceptance is asserted by this protocol. Every actual run must
bind source/test/runtime/input hashes, exact command, counts/skips, measured
residuals and all negatives. Historical failures remain separate immutable
receipts. Unit tests, engine agreement, field prediction and release acceptance
are separate gates. Do not raise tolerances, bounds or caps to erase a failure.

## Planner and physical controls

Exact-type traps cover dictionaries, string/scalar equality, array subclasses,
object/complex/float32/endian arrays, wrong shapes, masked reasons, duplicate
stations, empty source rights, mismatched frame and all nested unexpected keys.
Before finite scans/copy/hash/engine, test axis65/full4097/receiver2049/byte+1,
three-component projected magnetic-kernel accounting and bounded empty-container
metadata. Logical aliases count repeatedly; an invalid root is rejected before
full traversal. Negative tests never allocate a huge physical object.

Test nonuniform3x2x3 cells, sparse active holes, above/lateral receivers and
permutations. Reproduce origin1e16/width2 and width3 rejection, ordinary decimal
width acceptance and cumulative-node fidelity; this geometry tolerance remains
1e-10. Unit controls use signed densities, SI susceptibility, background-field
angles and null/scaling columns. Independently assemble prism bounds without
candidate/private forward helpers. Choclo gravity_u (m/s² -> mGal once) compare
at atol1e-10 mGal, rtol2e-8; magnetic components/TMI at atol1e-7 nT, rtol2e-8.
Physical Jacobian columns use unit density kg/m³ and mathematical unit SI
susceptibility outside the production0.1 bound; never submit chi1 to the engine.
Separate smooth-distant volume quadrature uses16/24/32 nodes; require24/32
convergence before comparing to analytical kernels at these frozen tolerances.
No production G may generate the only recovery evidence.

## Full inverse, sealed and adverse matrix

Tiny lambda0 baselines compare to independent SciPy bounded linear least squares
(BVLS), with independent Choclo G, own R and own whitening. Require relative
objective error<=1e-8, normalized model error<=1e-5 when strict positive
smallness makes the minimizer unique, prediction discrepancy<=1e-8 physical
units, normalized projected KKT<=1e-5. These mathematical controls are not field
recovery. Start modes: submitted interior/all-lower/all-upper/mixed and
baseline-concatenated; wide/tight physical bounds and both noise modes, including
bound stationary cases that must stop before a release direction.

24 submitted-survey cases=4 families x3 acquisition/noise regimes x2 noise modes:
co-structural signed compact body; density-only extra/disjoint susceptibility
body; flat/null property; undercovered/remanent-or-wrong-field model discrepancy.
Regimes: dense correct geometry; sparse blocked lines; shifted receiver geometry.
All observations generated independently by Choclo on a refined source mesh
different from inversion; use deterministic seeds1101..1124, immutable input
digests and frozen global acquisition splits before any fit. Truth evaluator
receives frozen selection only. Negative families need not converge or benefit;
retain per-case nonconvergence/ineligibility/unresolved rather than asserting24
improvements. Forced positive coupling is compared to lambda0 on disjoint sources
even when selection chooses uncoupled; don't remove that adverse candidate.

Noise modes are diagonal and SPD marginal covariance; all beta/lambda candidates
and two coupled starts stay visible. Selection tests mutate sealed values/truth
and require identical calibration/selected hashes; alter development values and
require real changed solves. Coverage/rank, null sensitivities and correlated
cross-partition errors must remain warnings, not unique-resolution claims.
Report each modality's train/validation/sealed WRMS and residual structure,
coupling and separate-model discrepancy; no average hides failed cells.

Measure nominal and largest admitted dimensions, malformed cap+1, deadline,
