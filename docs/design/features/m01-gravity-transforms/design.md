`correction_result + declared metric geometry + transform config -> strict replay admission -> immutable masked input view -> frozen outer spatial blocks -> inner blocked training selection -> train-only equivalent layer -> covered upward grids and conditional error maps -> withheld station prediction -> immutable local export and visual diagnostics`.

Ordinary modules: `data-pipeline/gravity_transforms.py` (engine/contract/selection/export) and `data-pipeline/gravity_transform_controls.py` (labelled independent volume-integral controls, no field substitution). New test file `tests/numerics/test_gravity_transforms.py`; existing exact station-processing gate and correction tests stay unchanged. Outputs are new directories under ignored `data/raw/gravity-m01-transforms`, or a user-selected external directory; canonical directories and existing outputs are forbidden.

## Typed request

Top-level exact keys: `schema_version=gravity-transform-request-1`, `correction_result`, `geometry`, `config`.

`correction_result` is the entire existing station processing output. Only `gravity_disturbance`, `bouguer_disturbance` and `terrain_adjusted_disturbance` are supported; observed absolute values are not spatial anomaly inputs. Admission reconstructs the known correction chain from original station values and its recorded configuration, compares the output hash, values, QC and propagated errors. This is verification only, never a second emitted correction. No provider anomaly is relabelled into a known state without that lineage.

`geometry` has exact `station_ids`, `easting_m`, `northing_m`, `upward_m`, `coordinate_unit=m`, `axis_order=easting,northing,upward`, `vertical_reference=WGS84_ellipsoid`, `metric_crs`, `mapping_citation`, `component=g_z_downward`, `data_unit=mGal`, `source_free_citation`, `geometry_error_model=fixed_geometry_conditional`, `geometry_error_citation`, `mask` and `mask_reasons`. All arrays match original station order, including masks. Upward coordinates must exactly match correction QC receiver heights. Coordinates and propagated sigma are finite, with sigma strictly positive; unknown errors are rejected. A mask is boolean and every masked row has a nonempty reason, every retained row has null reason. The dataset and all original rows are retained. No automatic exclusions, geographic projection or inferred heights occur.

`config` declares depths and positive dampings (at most 12 combinations), absolute target heights (at least highest receiver), grid region/spacing, coverage radius, spatial block shape, outer test fraction, seed, inner folds, minimum covered validation fraction, max input sigma, max conditional transfer sigma, max damped condition and `error_model` (`independent_stations` or `supplied_covariance`, the latter with a symmetric positive-semidefinite matrix and diagonal matching propagated SD squared). Independent errors reject nonzero shared density/geoid components. Covariance and error outputs are explicitly conditional on fixed geometry and preselected model; fit weights are diagonal even for a full covariance. Strict counts, finite bounds and known keys prevent ambiguous/resource-unbounded jobs.

## Method and diagnostics

Use actual Verde `BlockShuffleSplit(shape=..., random_state=...)` for one outer split and `BlockKFold` for inner training folds. Training XY alone become sources, on a plane at minimum train z minus candidate depth. Fit actual `harmonica.EquivalentSources(points=..., damping=..., parallel=False)`, with weights `1/sigma²`. The numerical transfer diagnostic reconstructs its column-scaled ridge system; `L@d` must agree with the engine before conditional propagated error is exported. Record singular values/condition of weighted unregularized design and damped system. A candidate violating condition/coverage is retained as failed, never silently winning.

Select depth/damping on covered inner validation normalized residual RMSE, never on outer values. Keep every fold/count/coverage and candidate comparison. Final model is fitted to outer training only, not all stations; outer holdout is inspected after selection. Grid support always uses outer training, including nearest-distance and hull masks; unsupported predictions/errors are JSON nulls with typed reasons. Candidate heights are evaluated by the frozen training transfer-error ceiling, with all comparisons/maps retained. A missing qualifying height has an explicit non-success precision verdict. Grid spacing below one third of training median nearest-neighbor spacing is rejected; extent at most 20 km, 400 stations, 12000 grid nodes, 8 heights, 12 candidates and 2..5 inner folds are reviewed local ceilings, not host-admission evidence.

Export full request, result/checkpoint, station predictions/masks/partitions, axes/grids/comparisons and SVG/PNG diagnostics in light/dark. Receipt names actual file byte counts and SHA-256, engine/module/source/config/split identities. Re-import/re-predict the selected layer must reproduce covered values. Field originals are only locally exported with retained rights, never committed. Scientific figures use equal-aspect metric maps, signed residual colour scales, labelled mGal and coordinate axes, masked holes, training/holdout markers, candidate CV/condition and height/noise curves. No marketing text or interpolated-density image.

## Independent verification and kill criteria

Volume quadrature controls contain multiple offset prisms, differing shapes/density signs, rotated/translated irregular station layouts and nonconstant heights. Analytic-prism versus converged quadrature tolerance: `1e-7 mGal`; inverse-distance Jacobian formula tolerance: `1e-12 m^-1`; transfer versus engine relative tolerance `2e-7`, absolute `1e-8 mGal`; control heldout/covered elevated-grid RMSE below `0.1 mGal` (authored smooth, buried sources, documented conditional range). Tolerances are predeclared physical/numerical gate targets, not field performance guarantees. Failed controls stop convergence and require an investigated design change, not a relaxed cosmetic gate.

Wrong unit/component/datum, missing positions/errors, altered lineage, mask ambiguity, high input noise above the declared budget, collinearity, inadequate blocks, overbounds and downward continuation are negative gates. Alternate depths/coefficient norms demonstrate layer nonuniqueness; coefficients never appear as density/geological truth. Read/write only this worktree and its owned environment. No source download, intake-tree edit, worker/API/browser implementation, merge or deployment.
