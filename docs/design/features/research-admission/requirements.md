# Research contribution and custom admission boundaries

| ID | Requirement | Verification |
|---|---|---|
| RA-001 | A manuscript SHALL cover declared method identifiers or other declared novel contributions. A non-method study SHALL use NC identifiers from the SDD Novel contributions section; it SHALL NOT have to claim an unrelated forecasting method. Identifiers in another section or code fences SHALL NOT authorize coverage. Empty and unknown coverage SHALL remain invalid. | `tests/test_novel_contribution_manuscripts.py::test_adversarial_novel_id_from_an_unrelated_section_is_not_a_declaration`, `tests/test_novel_contribution_manuscripts.py::test_adversarial_fenced_novel_id_is_not_a_declaration` |
| RA-002 | WHEN a product declares a readiness_provider Python script, THE readiness gate SHALL invoke that script's read-only validate(root) interface without importing the template engine. A missing, redirected, malformed or unsuccessful provider SHALL fail with a diagnostic. Products using custom admission SHALL declare the provider explicitly. The default product readiness computation SHALL remain available. | `tests/adversarial/test_adoption_defects_0_15_001.py::test_adversarial_a_stage_cannot_bring_its_own_provider_or_engine` |
| RA-003 | Notebook execution SHALL resolve the same declared notebook runtime and external role root as initialization, support a product-specific runtime name, and refuse a missing or ambiguous external runtime instead of silently using a legacy local directory or unrelated interpreter. | `tests/test_notebook_environment.py` |
