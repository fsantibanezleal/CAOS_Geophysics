# Acquisition and ingestion foundation requirements

Date: 2026-09-27. Parent: [approved product SDD](../../SDD.md), sections 2.1, 5, 6 and R-001 through R-004. This unit establishes the local source and raw-asset boundary. It does not certify a field inversion or activate an API method.

| ID | EARS requirement | Named failing gate |
| --- | --- | --- |
| AIF-01 | THE local pipeline SHALL load a versioned source ledger with unique stable IDs, declared format, provider object or manual acquisition, exact byte count and SHA-256 for acquirable external files, explicit rights decision, citation, and an ignored raw storage key. A metadata-only provider link SHALL instead identify its reported-but-unverified bytes/hash and have no raw key or acquisition. | `tests/data/test_sources.py::test_ledger_contract_and_rights` and `::test_stead_is_unverified_provider_metadata_only` |
| AIF-02 | WHEN a known source is acquired, THE pipeline SHALL verify bytes and SHA-256 before placing an immutable raw asset at its declared storage key and recording a receipt; a changed asset or receipt SHALL fail without overwriting either. | `tests/data/test_sources.py::test_immutable_raw_asset_and_receipt` |
| AIF-03 | IF an unlisted source ID, arbitrary URL, non-HTTPS fetch, unapproved redirect, or metadata-only provider-link acquisition is requested, THEN THE acquisition command SHALL reject it with the permitted source action and provider link. A rights `provider-link-only` entry MAY still allow an exact-object local comparison fetch when separately reviewed. | `tests/data/test_sources.py::test_source_allowlist_and_link_only` and `::test_stead_is_unverified_provider_metadata_only` |
| AIF-04 | WHEN `ingest.py --external` runs, THE pipeline SHALL process only the ledger's fetchable tutorial archives through the tar observation adapter; WHEN a selected EDI is supplied, THE pipeline SHALL dispatch it to EDI QC and never open it as tar. | `tests/data/test_ingest_dispatch.py::test_external_edi_never_opened_as_tar` and `::test_selected_edi_dispatch` |
| AIF-05 | IF an archive contains an unsafe, oversized, missing, duplicate, or malformed observation member, THEN THE adapter SHALL reject it; accepted observations SHALL preserve the source hash, unit and explicitly assumed uncertainty in an ignored derivative and receipt. | `tests/data/test_ingest_dispatch.py::test_archive_member_bounds_and_observation_contract` |
| AIF-06 | WHEN the Clear Lake `cl061` station is fetched or imported, THE pipeline SHALL require the pinned 16,411-byte EDI SHA-256, run transfer-function QC with the documented interpretation arguments, and report that its existing necessary 1D screen rejects layered inversion. | `tests/data/test_sources.py::test_clear_lake_source_pin` and `tests/data/test_ingest_dispatch.py::test_selected_edi_dispatch`; live-file gate `python data-pipeline/ingest.py --source-id clear-lake-cl061` |
| AIF-07 | WHILE pyGIMLi Slagdump and Koenigsee raw-data redistribution rights remain unresolved, THE ledger SHALL present commit-pinned provider links and hashes, permit only verified local import, and SHALL not mirror raw bytes in tracked or public artifacts. STEAD MAY appear only as a user-reported, unverified provider-linked metadata lead without touching the separately owned waveform phase. | `tests/data/test_sources.py::test_pygimli_provider_links_and_pins`, `::test_stead_is_unverified_provider_metadata_only`, and `::test_no_external_raw_tracked` |
| AIF-08 | IF acquisition or ingestion cannot proceed, THEN THE command SHALL name the source ID, failed check, expected input or corrective action without claiming a processed dataset. | `tests/data/test_sources.py::test_actionable_acquisition_errors` and `tests/data/test_ingest_dispatch.py::test_unsupported_adapter_is_explicit` |
| AIF-09 | THE source guide and data contract SHALL specify rights decisions, exact local commands, raw/derivative locations, physical meaning, uncertainty and outlier policy, EDI-versus-time-series distinction, and the boundary to future format verticals. | `tests/data/test_sources.py::test_documented_source_inventory` plus source-to-document review in `docs/design/features/acquisition-ingestion-foundation/convergence.md` |

Source hashes authenticate bytes, not a licence or scientific adequacy. A successful QC record is not an inversion verdict.
