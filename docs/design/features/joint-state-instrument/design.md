# Post-freeze accepted-state export

This additive protocol closes historical inspection gaps without altering the
calibration algorithm, objective, optimizer policy, candidate schedule, frozen
selection or original artifacts. Research: [verified primary source applicability](../../../methods/joint-survey-inversion/research.md),

## Offline sequence and integrity

A new strict CLI takes explicit external data root, development, sealed,
original workflow, exclusive output and disjoint scratch arguments. It validates
the original completed workflow and durable freeze, replays the genuine public
optimizer ledger with fixed source pins, then reads the committed sealed channel.
No sealed input reaches fitting or selection. Historical held-out curves are
post-selection diagnostics; repeatedly inspecting them cannot preserve a future
unseen-test claim. Export is not a new calibration or a precision certificate.

The new output contains a byte-exact copy of the original fixed inventory and
an additive `instrument/` native NPY1 directory with `instrument.json`. The old
workflow receipt still describes its original byte inventory. New payload binds
all original files by SHA256, freeze/development/calibration identities, native
source inventory and explicit false scientific/rights/activation claims. Original
completed-workflow validation continues to apply to the original directory; a
new bundle validator also compares every original byte with that directory and
recomputes every new frame. Failed workflows remain inspectable under the old
contract but cannot manufacture this completed post-freeze supplement.

## State arrays

For each actual candidate, retain its original `models_q` and physical trace.
Single-property fits have only that modality's response arrays and no two-property
coupling map. Coupled fits have both modalities. Each modality/partition exports
2D `[accepted_state, original_partition_row]` predicted, signed residual and
principal-marginal whitened arrays, and `[accepted_state, 3]` RMSE/WRMS/chi-square.
Rows and observations come from the original final result, never reordered or
repeated per state. No state metric affects the already frozen selection.
Actual uncoupled selected baseline pair is a separately labelled one-state
comparison, not an additional fit; the actual frozen selected model is also
exported. Nonconverged attempts retain all accepted states and literal stops.

## Exact coupling contributions

Use genuine loaded CrossGradient regularization_mesh public operators:
G=cell_gradient, B=diag(sqrt(vol))*average_face_to_cell. For normalized density
and susceptibility blocks a=G*q_rho and b=G*q_chi, export p=B*(a*a),
t=B*(b*b), h=B*(a*b), and c_i=Lc^4/V*(p_i*t_i-h_i*h_i).
The sum is checked against the genuine CrossGradient scalar at the existing
structural oracle absolute1e-10/relative1e-9 bounds, not a weakened gate. Signed
floating cancellation is retained. These are per-cell contributions to a discrete
dimensionless objective, not physical gradient vectors, field edges or per-cell
geological agreement. Lambda multiplies c_i only when an explicitly weighted
view is requested; lambda zero can have nonzero unweighted structure.
Independent shared-active-neighbor enumeration verifies p,t,h and contributions
on nonuniform dense/sparse meshes and null/sign controls. The distinct averaged
vector cross-gradient counterexample must remain unequal.
