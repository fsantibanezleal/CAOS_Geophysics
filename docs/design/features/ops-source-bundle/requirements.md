# Paired selected Git-blob source bundle requirements (proposal)

Status: PROPOSED for MAIN review, before code. Parent: [R-HFIX-06](../ops-host-fixture/requirements.md), [host protocol](../../../operations/02_isolated_host_fixture.md#immutable-selected-archive-route-no-git-metadata). Authorized scope is an ordinary selected-source prerequisite, not production admission, key authority, installer, host execution or full release packaging. PR #112 remains independently pinned at `5bc20eb3253c88c0cd903ccf06fc42aeb2a26b77`; this proposal is on a separate planning branch. Only NEW helper/tests/docs may be implemented after proposal review; no actual runtime, API, worker, migration, source verifier or ops_recovery edit.

R-SB-01 WHEN MAIN supplies two explicit read-only local Git repository roots and reviewed full runtime/ops commit IDs, THE builder SHALL inspect immutable commit/tree/blob objects only, disable replace-object/environment redirection, require each exact commit object and blob path/mode identity, and never read selected content from the worktree, mutable refs or `git archive`. Dirty filesystem changes SHALL neither enter the bundle nor be erased. Planned gate: tests/ops/test_source_bundle.py::test_committed_bytes_ignore_dirty_state.

R-SB-02 WHEN selecting paired source, THE builder SHALL require an independently reviewed SHA-pinned exact selection document, all paths required by the frozen verifier plus the exact reviewed app import closure, two disjoint runtime/ops inventories and bounded regular Git blobs only. It SHALL refuse symlinks/submodules, traversal/case aliases, unknown selection schemas/fields, missing/extra identity variants, private keys/secrets/native binaries/raw intake/backups/environments. Only the two explicitly required reviewed public EDI test fixtures are allowed as scientific input fixtures; no `data/downloads`/real-user raw/SQLite/archive/key content. Planned gates: ::test_selection_policy and ::test_object_identity_guards.

R-SB-03 WHEN building, THE builder SHALL produce one uncompressed bounded USTAR with `runtime/<path>` and `ops/<path>` FILE members only, stable lexical order and one explicit normalized epoch, uid/gid zero, empty uname/gname, mode0644, no PAX/GNU/extensions/directories/links/submodules. The same commits, selection, epoch and bytes SHALL produce byte-identical tar and compatible manifest on repeated builds in separate NEW output roots. Planned gate: ::test_deterministic_ustar.

R-SB-04 THE trusted manifest SHALL exactly match geophysics.ops-selected-source/v1: reviewed full runtime/ops commits, exact final archive SHA-256/bytes and every selected installed file's SHA-256/bytes, with no additional fields. A separate provenance receipt SHALL bind selection digest, commits/trees/Git blob OIDs/modes, per-file hashes, archive/manifest hashes, epoch, policy version and build tool provenance. Commit strings alone SHALL NOT be presented as Git-object provenance. Planned gate: ::test_paired_manifest_verifier_roundtrip.

R-SB-05 IF source/process/output/policy/size/hash validation fails, THEN THE builder SHALL fail closed without overwriting any existing directory/file, modifying a repository/environment/key/backup, performing network/service/installer operations or issuing a valid completed-build receipt. All outputs SHALL reside in one explicit NEW restricted root outside repositories and production; retained partial new output is diagnostic only. Source caps SHALL remain 4096 files, 8MiB/file, 64MiB total and 80MiB final archive; stderr/stdout/process duration SHALL be bounded. Planned gates: ::test_output_and_resource_guards and ::test_readonly_repositories.

R-SB-06 THE guide/receipt SHALL identify this as selected public source fixture provenance, not production trust/key authority, Git history signature, sigsum, complete secret-detection proof, admission, Linux execution, environment parity or deletion-durability acceptance. MAIN SHALL independently review the selection/object provenance and transmitted manifest digest, own immutable Linux installation without `.git`, and retain separate existing interpreter/environment provenance. No full clone/global safe.directory/native install is required. Planned gate: ::test_builder_guide.
