# Physical gravity project integration: current deployment stage

2026-10-08. Implementation scope is the already approved full product, not a
reduced single-account application. The current product SDD operating amendment
supersedes older feature prerequisites for external checkpoint providers,
off-host backups, SMTP, production account administration and a fixed whole-host
30% free-space threshold. Historical proposals and failed receipts stay intact.

- MC-01: authenticated accounts can persist immutable original physical station
  JSON and independently owned plural projects; no field metadata is inferred.
- MC-02: correction and transform jobs use the unchanged reviewed scientific
  contracts, saved input identities, actual bounded child computation and
  immutable parent/version/production relations. Flags are not corrections.
- MC-03: publication, cancellation, reservations, retained cleanup debt and
  owner-scoped deletion remain coherent through tested failure cuts. Unknown
  state stays preserved and blocked; no data-losing rollback or file sweep.
- MC-04: the selected-project instrument exposes actual original/current/additive
  quantities, uncertainties, transform prediction and signed residuals, ancestry,
  job parameters and complete exports, with bounded local verification.
- MC-05: internal database authentication, ownership and resource admission are
  required; no external email, independent checkpoint service or off-host backup
  is required to implement or qualify the owner-tested release. Optional restore
  tooling stays explicitly separate and cannot fabricate external freshness.
- MC-06: single-VPS activation requires actual integrated job, resource,
  cancellation, storage and browser evidence, with capacity for project bytes,
  configured scratch and current plus two qualified rollback releases.

Gates are the corresponding original R-MPV01..R-MPV17 feature specifications,
with external backup/freshness and the superseded 30% threshold excluded from
current release admission, not silently relabelled passed. The implementation
matrix must identify original, amended, executed and outstanding gates separately.
