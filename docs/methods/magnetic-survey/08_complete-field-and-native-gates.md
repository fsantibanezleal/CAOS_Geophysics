# Complete field bytes and native failure evidence

The bounded inverse accepts complete originals at most134217728 bytes and2048
original rows. These literal caps are not a complete Charleston workflow. A
larger acquisition must retain its full original/source rights and use a
separately designed full-file upstream workflow; a selected subset cannot close
that obligation. A compiled magnetic grid is not original flight-line data.

The Clear Lake author archive is separately attributed to its authors and the
underlying USGS release. The complete archive and complete magnetic CSV hashes
are checked before every original row is streamed for missing/nonfinite values.
No provider code, notebook, saved model or inferred geology is executed. Missing
acquisition elevation, vertical datum, measurement error and correction lineage
remain modelling-ineligible, not zero elevations or amplitude-derived noise.
An honest field evaluation can therefore be an exact retained FAIL/ineligibility
proof. It must not display synthetic S2 as the missing field experiment.

## Local native component, not a hosted profile

The fixed magnetic worker runs with startup hooks disabled and caller-explicit
existing packages/dependency roots. A real Windows Job is configured/read back,
the child is created suspended and assigned before release, and membership is
checked before numerical imports. The child closes its inherited Job lease so
parent last-handle death can stop it. Native cumulative CPU, process peak RSS,
job peak private committed bytes and scratch bytes are observed through drain.
No live PID sum becomes lifetime CPU and unavailable measurements are not zero.

Membership is also verified on the retained suspended child before resume.
Before assignment succeeds, failure stops that exact retained process handle,
not the empty Job. After assignment, failure stops the whole Job. The controller
pins the loaded public observation module and its direct support sources before
birth and after drain. Terminal signalled observations still enforce the same
CPU/RSS/private/scratch caps; exit zero cannot bypass an excess. Final settled
scratch bytes are recorded separately from sampled peak scratch. This is soft
file-byte observation, not a hard writable quota. The frozen matrix refuses a
generation when its actual lifetime has a resource cause or nonzero exit,
retaining that generation for diagnosis rather than calling it native acceptance.

This composes the separately reviewed provisional public line-survey Win32
operations; it is not the hardened native controller or its Linux equivalent.
Creation-bound birth, token/DACL/broker denial, complete parent publication tail,
settled final reads, scratch quota and durable hosted recovery require their
distinct native owner review. All native-security/online flags remain false.
The actual worker consumes complete original/request bytes and executes every
frozen fit; null and cancelled cases do not establish nontrivial field success.

Frozen S2 evaluation uses unchanged288-row/528-cell acquisitions, Choclo bodies,
conditional PCG64 noise, field/remanence negatives and exact quantity definitions.
The selected model is frozen before outer values. Zero-model baseline is
computed after that fit, within the same retained Job and original deadline.
Actual capped/failed fits keep full history and null selected model, never
partial candidate averages or a relaxed mesh/buffer/noise/certificate.

## Espanol

Los limites134217728bytes/2048filas no equivalen a procesamiento completo de
Charleston. Un subconjunto no cierra esa obligacion. La inspeccion del archivo
atribuido Clear Lake verifica bytes completos, miembros y todas las filas.
Altura, datum, errores o linaje ausentes mantienen ineligibilidad: no se inventan.

El worker fijo usa un Job real, suspension/asignacion antes de ejecutar,
verificacion de membresia antes de importar motores y cierre de la referencia
heredada. Conserva CPU acumulada, RSS, memoria privada comprometida y scratch
hasta vaciar el objeto. Es componente provisional local, no admision del
controlador endurecido, Linux ni servicio. Campos de admision permanecen falsos.
S2 conserva todas las verdades y adversos originales; un fallo/cap no se cambia
por un modelo alternativo, un promedio parcial o tolerancias mas debiles.

Antes de liberar se verifica tambien el proceso suspendido retenido. Si falla
la asignacion, se detiene ese handle exacto, no un Job vacio. Tras asignacion,
se detiene el Job completo. Las observaciones finales aplican los mismos limites
CPU/RSS/memoria privada/scratch incluso si el proceso termina con codigo cero.
Bytes finales estables y pico observado se distinguen; no son cuota dura. Una
generacion con rechazo de su vida nativa se conserva, sin aceptacion falsa.
