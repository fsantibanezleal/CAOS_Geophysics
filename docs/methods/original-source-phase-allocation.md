The literal `SourcePhaseQuadraticOperands` DTO identifies this prospective
source10 path. It has the same frozen physical fields as the historical
`OriginalQuadraticOperands`, with no phase flag, caller byte claim or callback.
Its canonical native runtime epoch is checked before arithmetic. The original
DTO keeps its exact conservative maximum and one-byte-short refusal, so
historical resource assertions and receipts are not reinterpreted. The public
magnetic owner constructs the new DTO from its actual unchanged native source.

This versioned fixed-quadratic numerical path retains the complete original
native source reserve and the numeric kernel's setup/action dictionaries. It
does not reduce a scientific or host memory limit from an observed RSS value.
The generic kernel certificate and the original-source certificate have
different endpoint workspaces. They do not execute simultaneously on this
source-owned path, so adding both complete certificate workspaces is not the
live phase envelope.

For the actual original operand payload `p`, its independent original
arithmetic dictionary `A`, and the unchanged native dictionaries:

    factory = native.setup + 2*p + metadata
    original_certificate = native.action + max(original_reserve, A)
    maximum = max(factory, original_certificate)

noise factor, observation/reference/bounds and sparse term is charged. Aliases
are not deducted. The arithmetic dictionary retains two operand/sparse copies,
all original endpoints, native row scratch and metadata. The terminal owner
additionally reserves its free endpoints, factors/transposes, residual witness
and retained native audits before any factory or source arithmetic allocation.
