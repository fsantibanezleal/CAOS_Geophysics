# Earthquake phase picking (M08 classical comparator; M13 learned)

Status: **real-data M13 benchmark computed and local browser parity verified; public release not yet verified**. The public 0.04.001 application does not execute this workflow. The earlier [fixture audit](../../data/derived/phase/fixture-audit.json) is only an exploratory ingestion and classical-baseline receipt; the separate [STEAD held-out benchmark](../../data/derived/phase/stead-heldout-benchmark.json) is the trained-model evidence.

## Physical observation and inference target

A seismometer records ground motion as a time series for each available component. The compressional P onset normally precedes the shear S onset for a local event, but the waveform also contains site response, noise, scattering, other events and instrument effects. Picking estimates two onset times, not a subsurface image or an earthquake location. Instrument counts cannot be labelled velocity or acceleration without response information. In the upstream engineering fixture, individual trace metadata label either m/s or m/s²; the two are not pooled as an amplitude scale.

For sample index `i` and sampling interval `Δt`, `t_i = t_start + i Δt`. A phase residual is `r_phase = t_predicted - t_analyst`; positive means a late automated pick. The tolerance event is `|r_phase| ≤ τ`, here an exploratory `τ = 0.5 s`. Analyst picks have their own uncertainty, so even `r ≈ 0` is agreement with a reference, not geological truth.

## Source, format and window

The official [PhaseNet repository](https://github.com/AI4EPS/PhaseNet) offers a 100-trace test-data archive with labelled P/S indices and mixed network/station/channel metadata. We downloaded that release asset into ignored local raw storage and verified exact SHA-256 `60476821a71697ded05884c225c75ae7e0099bd9a7b79c4e2bdc9e7b3a5706b3` (24,935,083 bytes). The source is [provider-linked](https://github.com/AI4EPS/PhaseNet/releases/download/test_data/test_data.zip), not copied into this public repository. The MIT notice applies to the PhaseNet code; it is **not** treated as permission to republish third-party waveform bytes.

The loader bounds archive entry count and expansion, refuses path traversal and duplicate names, prohibits pickle-bearing NPZ, and compares catalogue versus embedded station, event, unit, interval, channel and pick fields. It quarantines 7/100 traces with ambiguous 1/2/3 channel orientation; 93 retain an unambiguous E/N/Z component mask, including single-component recordings. Missing components remain masked. A component filled with zeros by the provider is not relabelled as a measured quiet channel.

This particular archive places P near sample 6000 and S from 6052 to 7327 at 100 Hz. A fixed 4096-sample window from source index 4096 contains both phases for its engineering audit. The window is fixed for all traces and does not use each analyst pick to choose a centre. **The archive is unsuitable for training:** a network could learn the almost fixed P clock position instead of an onset feature. User-supplied event windows need their own independent event-time/survey metadata and cannot inherit this archive-specific index. Each measured component has a trace-local mean removal and peak scale recorded for inverse visualization; this operation is not a substitute for response correction. Learned training will need to freeze exactly the same operation for browser inference.

## Leakage-safe split

The split algorithm forms connected components in a bipartite graph whose vertices are events and stations and whose edges are traces. An event or station appearing in several recordings therefore remains in one component. A salted SHA-256 assignment of components to train/dev/test makes both event and station disjoint. For the 93 eligible fixture traces, the fixed salt `phasenet-fixture-v1` gives 61/17/15. This is a procedural check, **not** a sufficiently powered generalization test; all partitions were inspected during the exploratory baseline run. A later final benchmark requires a larger independently sourced, rights-cleared cohort with an untouched test set.

## Classical M08 comparator

The current local comparator operates on the identical normalized window used for a future learned picker. For energy `e_i = Σ_c x_{i,c}²`, it computes

`C_i = mean(e_{i-STA+1:i}) / max(mean(e_{i-LTA+1:i}), ε)`,

with STA = 0.12 s, LTA = 1.2 s and threshold 2.5. Its first upward crossing is provisionally P; the next at least 0.4 s later is provisionally S. It never reads the analyst pick when selecting a crossing. This is deliberately a simple classical detector, not a seismic phase classifier. A noise burst can become P and a coda onset can become S. No second crossing is recorded as missing, not silently replaced by a labelled time.

The observed failure is substantial. With the declared 0.5 s tolerance, development P/S recall is 5/17 and 4/17; exploratory test P/S recall is 1/15 and 1/15. Median absolute errors on the exploratory test are 16.81 s (P) and 15.01 s (S), dominated by premature triggers. These figures argue against calling the baseline adequate and against presenting it as a polished online method. They remain in the committed receipt, including miss/outside-tolerance denominators. A serious M08 comparator needs response-epoch QC, event-time/velocity-informed gates or more robust waveform features, with those priors sourced independently of analyst pick labels.

## Learned M13 design and non-claims

[Zhu and Beroza's PhaseNet](https://doi.org/10.1093/gji/ggy423) estimates per-sample P/S/noise probabilities from three-component waveforms. A valid implementation must train or fine-tune a versioned model, preserve event/station split and normalization, calibrate thresholds on development only, and compare against M08 on the **same** held-out trace IDs. Record false picks per window, misses, timing residuals, network/station and unit strata, noise/channel-drop sensitivity, and negative results. A checkpoint that might have seen the test waveforms during pretraining cannot be called independent without upstream training provenance.

The browser export executes the frozen checkpoint on real, held-out waveforms. The declared gate requires offline and browser probability arrays to agree to maximum absolute float32 error ≤ 0.001 and peak times within one 0.01 s sample at fixed thresholds. The local browser run on 23 QC-valid preselected test records passed at `4.41e-6` maximum error and zero peak-sample difference; one QC-rejected record remained without inference. Curves alone are not accuracy evidence; source, model hash, normalization, threshold and label uncertainty remain visible. **This is local parity, not deployment or public-release verification.** The 100-trace fixture remains inadequate to close [BL-050](https://github.com/fsantibanezleal/CAOS_Geophysics/issues/83).

The [original PyTorch phase model](../../data-pipeline/phase_model.py) is a PhaseNet-family one-dimensional encoder-decoder, **not bitwise-equivalent official PhaseNet**. It accepts exactly 60 s at 100 Hz, three channels in E/N/Z order; five resolution levels (16, 32, 64, 128 and 192 feature channels) and residual convolution blocks output N/P/S logits. A soft target places Gaussian P and S arrival kernels of 15 samples standard deviation around the analyst indices. Weighted soft cross-entropy upweights the sparse arrival samples by 12 relative to noise. Such weighting does **not** calibrate probabilities: displayed outputs are model scores, not calibrated likelihoods. Inference peak selection uses development-selected P/S thresholds of 0.8 and a minimum P-S separation of 0.4 s. The frozen 12-epoch CUDA checkpoint is bound to the source, code, split and pre-test threshold receipt; it is not the official pretrained PhaseNet model.

For a larger training/held-out source, the [STEAD origin](https://github.com/smousavi05/STEAD) labels its dataset CC BY 4.0. The [SeisBench metadata mirror](https://seisbench.gfz-potsdam.de/mirror/datasets/stead/) was downloaded locally and SHA-256-verified (402,560,190 bytes; `9b9007406ebfef8c182060c8bb4266d29bbc433985f91f7e2dc476c8aca08efe`). Its [aggregate profile](../../data/derived/phase/stead-metadata-profile.json) has 1,265,657 rows, including 745,012 valid P-before-S earthquake traces. The mirror's provided trace-level split repeats 59,820 events and 1,942 stations across train/dev/test among eligible records: it is **not** the required independent split. Hashing events and stations separately and retaining only agreeing assignments yielded 397,686/11,777/14,754 train/dev/test trace candidates and quarantined 320,795 mismatches. A stricter [selection receipt](../../data/derived/phase/stead-selection-profile.json) additionally requires both picks to be manual, a documented bucket slice and known channel identity: 498,116 quake-or-noise rows remain eligible after all filters. The metadata-only hash-ranked inventory reserved 60,000 quakes plus 5,000 noise windows for training and 5,000 quakes plus 1,000 noise windows each for development and test. The selected event and station IDs do not cross partitions. That selection preceded all waveform access and scoring; the sealed test waveforms were opened later for the locked held-out evaluation.

The [SeisBench format specification](https://seisbench.readthedocs.io/en/stable/pages/data/data_format.html) declares waveform dimension order, component order, sample rate and unit, and maps each metadata `trace_name` to a data block and slice. The candidate mirror stores three-channel **unrestituted instrument counts**, not m/s; normalization is trace-local and label-independent, with original counts and per-component scale preserved locally. The [strict HDF5 adapter](../../data-pipeline/stead_phase.py) and synthetic format tests refuse an undeclared order, rate, unit, nonfinite samples, flat channel or non-bucket path. The [waveform source receipt](../../data/derived/phase/stead-waveform-source.json) pins the complete 91,127,786,704-byte HDF5 to local SHA-256 `4d73f567d9ea85fcdea5f2d8bf9cf47fd2e0c25b602793d41f56713efba62b1b`; no matching upstream checksum was published. The HDF5 format read passed. An independent SeisBench 0.11.5 reader and the strict adapter returned identical unrestituted counts for three hash-selected training and three development traces (maximum absolute difference 0; private receipt generated by `scripts/verify_stead_seisbench.py`), without opening selected test waveforms. The [aggregate train/development QC receipt](../../data/derived/phase/stead-train-dev-qc.json) verifies 64,599/65,000 training and 5,850/6,000 development traces against the extracted-array hashes. It retains 54/58 flat-component failures and 347/92 exactly duplicated-component failures in train/development respectively. The later sealed test extraction retained 19 flat-component and 55 duplicated-component failures, so 5,926/6,000 test traces were usable. The invalid traces stayed in the benchmark denominator as unpicked. STEAD's README warns of misplaced back-azimuths and some duplicated-component noise traces. SCEDC's [deep-learning collections](https://local.scedc.caltech.edu/data/deeplearning.html) are another official route, but the 9 GB P-picking file alone does not solve the P/S benchmark.

The [train/development pick-position profile](../../data/derived/phase/stead-pick-position-profile.json) exposes a strong construction prior: all 60,000 selected training and 5,000 development P arrivals are between samples 400 and 1000 of a 6000-sample window. No test-label distribution was computed. Ordinary held-out accuracy alone could therefore reward a clock prior rather than waveform physics. Training now translates each labelled window over the broad feasible range while keeping both phases inside the record and pads from the same trace's pre-event quiet segment; this augmentation is an approximation, not a new measured trace. The predeclared test compares M13 and M08 with an input-free training-median position control and a fixed +800-sample shifted-window challenge, reporting out-of-window exclusions. A learned advantage must survive these controls before any general phase-detection claim.

The [original STEAD repository](https://github.com/smousavi05/STEAD) includes the [CC BY 4.0 license text](https://github.com/smousavi05/STEAD/blob/master/LICENSE). The [SeisBench STEAD adapter](https://github.com/seisbench/seisbench/blob/main/seisbench/data/stead.py) independently declares the same per-dataset license. The GFZ [mirror notice](https://seisbench.gfz-potsdam.de/mirror/LICENSE) says dataset licenses vary and refers to those declarations; it does not apply SeisBench software's GPLv3 license to STEAD. Any released trace derivative or model must retain Mousavi et al. (2019) attribution, source and license links, and a modification notice. An asset-level rights and attribution check remains a release gate.

## Staged real-waveform computation

The [CUDA training command](../../scripts/train_stead_phase.py) opens only hash-checked, QC-valid training and development arrays. It records optimizer and epoch losses, chooses a checkpoint by development loss, then fixes P/S peak thresholds by development macro-F1. The private freeze receipt binds the checkpoint bytes, full waveform source and untouched test inventory. The [held-out evaluator](../../scripts/evaluate_stead_phase.py) refuses test bytes without that receipt, compares M08 and M13 on the same trace IDs, and counts unreadable test waveforms as unpicked with a separate QC denominator. Its predeclared stress variants remove each channel or add deterministic noise; output includes per-phase tolerance confusion, timing, noise false alarms and network/channel strata. The real-source training and one-pass test evaluation have completed. Softmax outputs remain uncalibrated scores unless a separate reliability study establishes calibration.

### Locked STEAD test result

The [aggregate held-out receipt](../../data/derived/phase/stead-heldout-benchmark.json) covers the 5,000 metadata-selected earthquake and 1,000 noise traces, including 74 QC failures. P/S analyst picks, not a geological model, are the references. A pick is correct if it is within ±0.5 s of the analyst index; an out-of-tolerance pick counts as both a false positive and a missed reference. M00 predicts only the training-median clock positions with no waveform, and M08 uses a fixed simple STA/LTA energy trigger on exactly the same normalized trace.

| Condition | M00 P/S F1 | M08 P/S F1 | M13 P/S F1 |
| --- | ---: | ---: | ---: |
| Nominal held-out | 0.154 / 0.080 | 0.083 / 0.025 | 0.981 / 0.955 |
| Input shifted +8 s, labels shifted | 0 / 0 | approximately 0.05 / 0.01 | approximately 0.98 / 0.96 |
| Added normalized Gaussian noise σ=0.1 | approximately 0.15 / 0.08 | approximately 0.55 / 0.55 | approximately 0.77 / 0.75 |

At nominal conditions, M13 correct-within-tolerance counts are 4,903/5,000 P and 4,759/5,000 S. The valid-noise false-pick rates are 1.07% P and 0.64% S. Median absolute residuals among records with both a pick and reference are 0.03 s P and 0.05 s S; these conditional timing summaries do not include misses. The +8 s variant was predeclared, with all 6,000 selected records eligible for that translation. Removing Z reduces P F1 to approximately 0.90; dropping E or N reduces S F1 to approximately 0.93. The artificial noise stress is a material degradation, not field noise generalization. The [post-score overlap audit](../../data/derived/phase/stead-heldout-overlap.json) found no repeated event or station IDs and no exact normalized 3×6,000-sample waveform duplicates within or across the three selected partitions (64,599/5,850/5,926 QC-valid). That audit cannot detect approximate copies, related events under different IDs or source label errors. Source/station disjointness and a shifted-clock control reduce specific leakage risks, but do not establish transfer to another catalog, unseen instrument response or calibrated uncertainty. The simple M08 trigger is a negative comparator, not a competitive modern baseline.

Before opening the sealed test waveforms, a [development-only checkpoint screen](../../scripts/profile_stead_phase_dev.py) compares M13 against M08 and an input-free training-median clock control on the same development traces, both nominally and after the fixed +800-sample translation. It writes only a private aggregate receipt. This set selected the model epoch and thresholds, so its scores are an internal sanity check, never independent accuracy evidence; a poor screen is grounds to stop before consuming the test partition.

Before GPU fitting, the training command also hashes each complete normalized train/development waveform and rejects an exact array copied across partitions, even if its event and station metadata differ. It records within-partition exact-duplicate counts in the private freeze receipt; this is an additional overlap gate, not proof against approximate copies or mislabeled source events.

Training saves an ignored, code/source/split-bound continuation state after each epoch. A local CUDA interruption/resume test produced bit-identical final model tensors to an uninterrupted two-epoch run. The decoder uses exact-nearest upsampling followed by learned convolutions because CUDA linear-interpolation backward is not deterministic under the declared PyTorch policy. This synthetic continuity test does not establish real-trace accuracy.

The first full-source CUDA attempt stopped after epoch 1 when the fp16 dynamic scale grew from 65,536 to 131,072 and a later gradient norm became non-finite. It left only a private continuation state, no frozen checkpoint and no test read. The trainer now skips that update, halves the scale, records the skipped-step count and aborts if overflow persists beyond the declared per-epoch bound. A new run must use a new output directory because the training code hash changed; the interrupted state is retained for audit, not silently resumed under different code.

The [ONNX exporter](../../scripts/export_stead_phase_onnx.py) binds the frozen checkpoint to a private model, removes exporter stack-trace metadata containing absolute host paths, and checks native-runtime probabilities and peak times against 16 hash-selected development traces. The sanitized export has SHA-256 `4e5962ed0a9037e545991c218ae770ae7aff2c01f1e6a919c338705780ce5f4c`; native ONNX versus PyTorch maximum absolute probability difference is `1.07e-6`, with no peak-time difference on those development traces. [Public asset preparation](../../scripts/export_stead_browser_assets.py) binds that exact model to the predeclared 24-record held-out display cohort: 23 QC-valid normalized waveforms and one unchanged QC rejection. The [private held-out parity oracle](../../scripts/prepare_stead_browser_oracle.py) compares all 23 actual assets against PyTorch and native ONNX (maximum `1.49e-6`, zero peak-sample difference) while keeping expected arrays ignored. Those **native** checks are separate from the later [browser parity test](../../frontend/scripts/verify-phase-browser-parity.mjs), which executed the served assets in Playwright Chromium against the private PyTorch oracle and passed at `4.41e-6` maximum absolute probability error with zero peak-sample error. The manifest's `browser_parity_verified:false` records its earlier export state; the subsequent browser test and [M13 browser design record](../design/features/m13-browser/design.md) document the local verification. Public hosting and release acceptance remain separate gates.

Before held-out scoring, a [metadata-only browser-display selection](../../data/derived/phase/stead-browser-selection-profile.json) was fixed: 16 earthquake and 8 noise traces across declared network strata, two per stratum, with SHA-256 rank independent of waveform values or model performance. Its trace identities remain private until the asset-level rights review. This small display/parity subset is not the accuracy denominator: all 6,000 selected held-out traces, including QC failures, define the locked benchmark.

## Reproduce the local STEAD pipeline

The source requires over 92 GB before extracted arrays; choose a roomy local volume outside public web assets. The downloader keeps interrupted transfers as `.partial`, resumes them, and verifies complete byte counts and the locally pinned SHA-256 values. The separate SeisBench environment is an independent reader, not the CUDA training environment.

```powershell
$sourceDir = 'E:\CAOS_Geophysics\raw\stead'
$sourceHash = '4d73f567d9ea85fcdea5f2d8bf9cf47fd2e0c25b602793d41f56713efba62b1b'
./scripts/fetch-stead-phase.ps1 -Destination $sourceDir
py -3.12 -m venv .venv-seisbench
.\.venv-seisbench\Scripts\python.exe -m pip install -r data-pipeline/requirements-phase-seisbench.txt
.\.venv-pipeline\Scripts\python.exe scripts/select_stead_phase.py --metadata "$sourceDir\metadata.csv"
.\.venv-seisbench\Scripts\python.exe scripts/verify_stead_seisbench.py --source-dir $sourceDir
.\.venv-pipeline\Scripts\python.exe scripts/extract_stead_phase.py --waveforms "$sourceDir\waveforms.hdf5" --waveform-sha256 $sourceHash --partition train
.\.venv-pipeline\Scripts\python.exe scripts/extract_stead_phase.py --waveforms "$sourceDir\waveforms.hdf5" --waveform-sha256 $sourceHash --partition dev
.\.venv-pipeline\Scripts\python.exe scripts/summarize_stead_phase_qc.py
.\.venv-pipeline\Scripts\python.exe scripts/train_stead_phase.py --batch-size 32 --epochs 12 --output-dir data/raw/phase/models-new
```

The output directory must be new; a code change cannot resume an earlier source/code-bound training state. Inspect the private freeze receipt and train/development ledger before unlocking test extraction. Only then run `scripts/extract_stead_phase.py --partition test --frozen-checkpoint data/raw/phase/models-new/phase-freeze.json`, followed by `scripts/evaluate_stead_phase.py` and `scripts/export_stead_phase_onnx.py` with explicit paths to the same frozen receipt. These steps do not alone establish browser parity or release rights.
