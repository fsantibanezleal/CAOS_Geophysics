# Attribution and rights for the STEAD browser assets

Waveforms originate from STEAD: Mousavi, S. M., Sheng, Y., Zhu, W., and Beroza, G. C. (2019), *STanford EArthquake Dataset (STEAD): A Global Data Set of Seismic Signals for AI*, IEEE Access. DOI: [10.1109/ACCESS.2019.2947848](https://doi.org/10.1109/ACCESS.2019.2947848). Original source: [STEAD repository](https://github.com/smousavi05/STEAD). The dataset-specific license is [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), as identified by the [source repository](https://github.com/smousavi05/STEAD/blob/e6f247cf174e4aaefe01a6fcc72a0e88296d42b4/LICENSE) and the dataset-specific [SeisBench adapter](https://github.com/seisbench/seisbench/blob/e5616ad33c00aba75d5130b44222df46b41e4094/seisbench/data/stead.py). The local source download came from the [SeisBench mirror](https://seisbench.gfz-potsdam.de/mirror/datasets/stead/). SeisBench software uses a separate license; its software license is not applied to STEAD data here.

This package modifies the source records. A metadata-only event/station-disjoint protocol fixed the 24-record display selection before test scoring. Source Z/N/E unrestituted instrument counts were reordered E/N/Z; flat or exactly duplicated components were quarantined. The 23 usable 60-second records were mean-removed and divided by each component's peak centered count. The binary files are little-endian float32 dimensionless normalized counts, not velocity or acceleration. One selected noise record failed QC, has no waveform bytes, and was not replaced. These are changes to the source material.

The ONNX model is a project-authored PhaseNet-family architecture trained from scratch on the STEAD training partition. It is not the official pretrained PhaseNet model and is not endorsed by the STEAD authors or SeisBench. The package includes the frozen [aggregate held-out benchmark](benchmark.json), and the model and waveform hashes in [manifest.json](manifest.json). Private training arrays are not included. Model scores are not calibrated event probabilities; analyst picks are references, not geological truth. The ONNX model and benchmark summary are distributed under CC BY 4.0 in this package; repository source code remains under Apache-2.0.

The browser parity gate is distinct from native ONNX parity. A local Playwright Chromium run compared all 23 valid held-out records with a frozen private PyTorch oracle: maximum absolute probability difference `4.41e-6`, zero P/S peak-sample difference, and one QC rejection retained without inference. The manifest's `browser_parity_verified:false` records its earlier export state; the [browser design and verification record](../../../../../docs/design/features/m13-browser/design.md) documents the subsequent test. This does not establish a deployed public release or cross-dataset accuracy.
